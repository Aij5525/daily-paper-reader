## 摘要
通信系统可以复用其发射信号进行感知，而无需专用的雷达发射。对于已建立的DFT预处理正交啁啾复用(DFT-P-OCDM)波形，当双选择性信道中的多条物理路径落入同一延迟-多普勒单元时，此任务变得困难。在这种情况下，从导频推断出的可分辨延迟类别数量可能小于同一单元内物理路径的数量。这种不匹配增加了路径数目确定、分数多普勒偏移估计和信道重建的难度。我们针对双选择性信道在DFT预处理菲涅耳(DPF)域中推导了输入与输出之间的逐点关系，其中多条路径位于同一延迟-多普勒单元内。基于该输入输出关系，我们提出了两阶段超高分辨率(TSUR)框架。第一阶段利用相位渐进导频估计延迟，第二阶段利用泄漏样本估计多普勒和每个延迟类别内的路径数目。此外，我们推导了CRLB，并分析了导频配置如何在感知分辨率与通信恢复之间进行权衡。仿真结果表明，TSUR能够分辨同一延迟-多普勒单元内的同延迟路径，对现有延迟偏移保持鲁棒性，并且相比顺序提取和离网格基线实现了更低的分数多普勒估计误差。

## Abstract
Communication systems can reuse their transmitted signals for sensing without dedicated radar transmissions. For an established DFT-preprocessed orthogonal chirp division multiplexing (DFT-P-OCDM) waveform, this task becomes difficult when several physical paths in a doubly selective channel fall into the same co-delay-Doppler bin. In this case, the number of resolvable delay classes inferred from the pilot may be smaller than the number of physical paths within the co-bin. This mismatch increases the difficulty of path number determination, fractional Doppler offset estimation, and channel reconstruction. We derive a pointwise relationship between the input and output in the DFT preprocessed Fresnel (DPF) domain for doubly selective channels with multiple paths within the co-delay-Doppler bin. Based on this input and output relation, we propose the two stage ultra high resolution (TSUR) framework. The first stage uses pilots of the phase progression to estimate delay, while the second stage uses the leakage samples to estimate the Doppler and the number of paths within each delay class. Furthermore, we derive CRLBs and analyze how the pilot configuration trades sensing resolution and communication recovery. Simulation results demonstrate that TSUR resolves same delay paths within a co-delay-Doppler bin, remains robust to exist delay offsets, and achieves lower fractional Doppler estimation errors than sequential extraction and off-grid baselines.

## 一、论文的核心问题与整体含义

- **背景**：面向 6G 通信感知一体化（ISAC），通信系统可复用自身发射信号进行环境感知，无需专用雷达。在双选择性信道（同时存在时延扩展与多普勒扩展）中，多径的连续时延、多普勒参数是感知的关键观测量。
- **核心问题**：在 DFT 预编码正交啁啾复用（DFT-P-OCDM）系统中，当多条物理路径共享同一个“整数时延‑多普勒 bin”（即落入同一 co-delay-Doppler bin）且连续时延间隔小于分辨率极限时，接收端从导频中能分辨的“时延类”数会少于实际物理路径数。这种“bin 内多径”会造成：
  - 路径数的误判；
  - 分数多普勒偏移难以准确估计；
  - 后续信道重构与数据恢复性能下降。
- **研究含义**：本文旨在解决通信辅助感知中“同 bin 多径”的高分辨率分辨问题，为 DFT-P-OCDM 波形在多径参数估计时提供一种既考虑时延相位、又利用多普勒泄漏结构的两阶段超高分辨率（TSUR）方案，同时给出理论性能界。

## 二、论文提出的方法论

### 1. 核心思想
- 推导了 **DPF 域（DFT 预处理 Fresnel 域）输入输出逐点关系**。
- 关键数学结论：在 DPF 域中，**时延表现为导频块之间的相位递进**（相位旋转），而**分数多普勒表现为围绕整数 Doppler 索引周围的局部泄漏样本**。这种解耦使时延与多普勒可分层估计。
- 提出 **TSUR（Two Stage Ultra-high Resolution）框架**：  
  - **第一阶段**：利用“相位递进导频”估计可分辨时延类数目与连续时延值；
  - **第二阶段**：利用“局部泄漏样本”估计同一时延类内的物理路径数、分数多普勒偏移与复增益。

### 2. 关键技术细节与流程
- **系统/信道模型**：
  - 信道建模为多径叠加：\( H = \sum h_i T(d_i)\Delta(\nu_i) \)，其中归一化时延 \(d_i = l_i+\delta_i\)、归一化 Doppler \(\nu_i=k_i+\kappa_i\)。
  - 将分数时延的 Dirichlet 函数脉冲化（\(p\) 泄漏）和分数多普勒的有限傅里叶展开（\(q\) 泄漏）代入 Fresnel 域信道，最终在 DPF 域得到等价的循环移位 + 相位叠加形式。
- **DPF 域输入输出关系**：
  \[
  y_{\rm DPF}(m)=\sum_i \sum_p \sum_q h_i \Lambda_N(p,\delta_i)\Gamma_N(q,\kappa_i)
  e^{j\pi b_{i,q}^2/N} e^{-j2\pi m(s_{i,p}+b_{i,q})/N}x([m-b_{i,q}]_N)+e_w(m)
  \]
  - 符号 \(b_{i,q}=k_i+q\) 决定循环移位，符号 \(s_{i,p}=l_i+p\) 只出现在相位项中。
  - 说明 DFT-P-OCDM 将 **时延写成相位、多普勒写成移位**，从而在模型层面解除两者在 DFnT 域的耦合。
- **导频布置（ULPA 帧）**：
  - 在 DPF 域每 \(D_{\rm pilot}\) 放置一个受保护导频块（中心导频 + \(2G\) 个保护零），共 ζ 个。
  - 通过相关/阈值得到整数 Doppler 索引 \(k_c\)；导频间隔需满足 \(D_{\rm pilot}\ge 2G+1\) 且 \(G\ge\max|k_i|\)，以保证 Doppler 范围覆盖与块间不重叠。
- **第一阶段：时延类估计**
  1. 提取每个导频块主样本 \(y_\xi(0)\)，形成关于时延 \(d_i\) 的多快拍相位序列；
  2. 用 **FBSS（前向‑后向空间平滑）** 处理相干分量；
  3. 用 **MDL 准则** 确定可分辨时延类数目 \(K_d\)；
  4. 用 **FBSS‑MUSIC** 得到粗时延；
  5. 用 **Newton 迭代** 最大化解释协方差的投影矩阵迹（集中似然准则），细化时延。
- **第二阶段：bin 内多普勒/路径数估计**
  - 以检测到的整数 Doppler 为中心，截取局部窗口（±Q 样本）；
  - 对“主样本 + 局部泄漏”构建路径响应字典；考虑当前导频与相邻 R 个导频的泄漏贡献；
  - 使用 **NMLL-MLE（近主瓣泄漏最大似然）** 循环搜索分数多普勒对给定候选路径数进行集中最小二乘拟合；
  - 采用 **BIC** 选择最优路径数模型（候选数须小于可辨识约束 \(N_{\rm st} > K_M + K_{\rm ext}\)）；
  - 最后通过最小二乘得到复增益与残余干扰项增益。
- **CRLB 推导**：给出在“已正确识别阶数”条件下的 Fisher 信息矩阵与 CRLB，作为估计精度理论基准。

## 六、主要结论

1. **DPF 域模型证实**：在 DFT-P-OCDM 中，主样本的相位递进反映连续时延；局部泄漏样式反映分数多普勒；二者可在不同导频样本上解耦。
2. **TSUR 可有效分辨同 bin 多径**：能在路径数未知且分数多普勒可能相同的条件下，正确判断时延类与类内物理径数。
3. **分数 Doppler 估计明显优于基线**：比 ZP-PCTD/OMP 更接近 CRLB；保留相邻导频相互作用（R>0）可消除系统误差；
4. **对同 bin 内的时延失配（Δd>0）具有鲁棒性**：即使第一阶不将两径分开，第二阶段仍能恢复分数多普勒，代价仅有约 4 dB 的精度损失（相对 orcale）。
5. **导频配置权衡**：固定能量时，少量高功率导频有利于低信噪比下路径数的判定；而更多导频块有利于连续参数估计、信道重构和数据检测——感知分辨率与通信恢复之间存在折衷。

## 七、优点

- **理论公式完备**：从基带信道模型推导到 DPF 域逐点输入输出，给出闭式解析关系，为算法设计提供数学基础。
- **峰与泄漏分层解耦**：将时延（相位）与多普勒（移位/泄漏）分配到两个独立观测域，属于新颖且工程可解释性强的设计。
- **层次化模型判定**：采用 MDL 检测时延类数、用 BIC 检测类内路径数，避免事先假设路径数。
- **复杂度可控**：可通过 Q/R 参数在精度与计算之间折衷；并指出全相互作用模型中可保留主导项从而减约 63% 成本。
- **理论界完整**：推导了延迟与多普勒参数联合的 CRLB，使仿真有界可比。
- **公平基线比较**：引入存在顺序提取误差和栅格限制的 ZP-PCTD/OMP 等方法，凸显 TSUR 的超分辨优势。

## 八、不足与局限

- **缺乏实测数据验证**：现阶段结果为理想化蒙特卡洛仿真，未考虑真实信道中的非高斯噪声、遮挡体去相关、收发残余频偏和硬件非线性等。
- **泄漏模型对波形特异**：作者自己指出扩展至 AFDM 需重新推导并建立对应分辨框架，因此普适性有限。
- **复杂场景覆盖有限**：未验证多于两径在同 bin、不同 bin 之间的强泄漏、双基非平稳信道等。
- **计算代价仍需后续工程化**：NMLL-MLE 在假设空间中使用多维/多候选搜索，可能在大规模基站‑感知节点部署中面临实时性压力。
- **CRLB 是“条件界”**：推导建立在模型阶数正确给定的假设上，并未把路径数误判纳入紧致度量。
- **未报告实际训练/计算的资源消耗**，难以据此评估部署成本和能耗。

## 结语

本文从理论上揭示了 DFT-P-OCDM 在 DPF 域将时延反映为相位、多普勒反映为移位的核心特性，并据此构建了两阶段超高分辨率 TSUR 框架，以实现同 co-delay-Doppler bin 内多径的可分辨估计。实验证明其超分辨能力、鲁棒性与导频配置优化作用，为通信辅助感知的前端多径参数估计提供了有效方案；但结果仍以仿真为主，后续仍需真实环境验证和跨波形泛化研究。
