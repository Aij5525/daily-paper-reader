## 摘要
本文提出了一种分散学习框架，该框架同时考虑了功率控制和隐私保证。具体而言，我们使无线多播网络中的一组客户端能够联合训练一个共同模型，同时保持每轮迭代预设的最大隐私泄露水平。通信网络由行随机邻接矩阵表示，从而能够捕获非对称信道增益以及异构的最大发射功率水平。通过显式的功率分配策略实施差分隐私，该策略将每个节点有限的最大发射功率分配给模型系数和注入的高斯噪声，从而联合控制学习性能和隐私泄露。我们进一步证明了所提出的算法实现了O(log T)的累积遗憾界，其中T表示时间范围。为了评估我们方法的实际性能，我们在CIFAR-10数据集上进行了全面的实验，涵盖了IID和非IID数据分布，并考虑了不同的隐私级别、不同的客户端数量以及各种图拓扑。结果表明，在所考虑的设置中性能强劲，并且优于现有方法，突显了所提出算法在现实无线通信约束下的有效性。

## Abstract
In this paper, we propose a decentralized learning framework that incorporates both power control and privacy guarantees. Specifically, we enable a set of clients in a wireless multicast network to jointly train a common model while maintaining a prescribed per-iteration maximum privacy leakage level. The communication network is represented by a rowstochastic adjacency matrix, allowing us to capture asymmetric channel gains as well as heterogeneous maximum transmit power levels. Differential privacy is enforced through an explicit powersplitting strategy that allocates each node's limited maximum transmit power between model coefficients and injected Gaussian noise, thereby jointly controlling learning performance and privacy leakage. We further prove that the proposed algorithm achieves a cumulative regret bound of O(logT), whereTdenotes the time horizon. To evaluate the practical performance of our approach, we perform comprehensive experiments on the CIFAR-10 dataset under both IID and non-IID data distributions, considering different privacy levels, diverse numbers of clients, and various graph topologies. The results demonstrate strong performance across the considered settings and improved performance over existing methods, highlighting the effectiveness of the proposed algorithm under realistic wireless communication constraints.

## 1. 论文的核心问题与整体含义

### 研究动机与背景
- 分散式学习（DL）近年兴起，训练过程中节点仅与邻居交换参数而非依赖中央服务器；很适合车联网、智能城市、传感器网络等天然分布式场景。
- 无线多播 + 空中计算（OAC）能高效地让多节点在共享无线信道上叠加交换模型更新，但实际系统面临三方面挑战：
  1. **链路异构**：信道增益不对称、链路有向且不可能天然满足“双随机”邻接矩阵假设，而许多现有算法依赖这一理想条件；
  2. **功率受限**：节点发射功率受限且异构，现有方法缺乏一种在“传模型”和“注入噪声”之间分配有限功率的机制；
  3. **隐私威胁**：中途窃听或“诚实但好奇”的邻居可以从传输的模型系数中反推用户原始数据。

### 论文目标
将功率控制与差分隐私（DP）纳入同一个分散学习框架中——每个节点把有限功率拆分给模型系数传输和 DP 噪声注入，从而在异构无线多播网络中实现既收敛、又满足预定每轮最大隐私泄漏上限的联合训练。

### 与已有工作的差距
- 许多 DP-DL 算法假设通信图平衡或无向（即双随机矩阵），现实中难以实现；
- 针对有向图的行随机方法（push-sum / push-pull）权重设计复杂，与无线信道特性脱节；
- 已有引入 DP 的无线分散学习大多把噪声注入抽象化，未考虑具体的发射功率约束，也无法系统地平衡隐私与精度。

## 2. 论文提出的方法论

### 核心思想
- 利用无线广播的天然特性构造**行随机邻接矩阵 A**：每个接收节点将各邻居传来的信号按照信道系数、发射功率归一化，归一化后每行之和为 1。
- 将每个节点的总功率 Pi 分为两部分：αiPi 用于承载模型系数 xi,t，βiPi（= (1−αi)Pi）用于承载 DP 高斯噪声 ηi,t ：  
  **x̃i,t = √(αiPi) · xi,t + √(βiPi) · ηi,t**
- 通过求解一个线性规划来获取 αi 和 βi：
  - 目标：最大化全部 αi 之和（即尽量多功率传给模型信息）
  - 约束：所有邻居间的每轮差分隐私泄漏 ϵij ≤ ϵmax
- 由于 σi,t ∝ γt（γt 为递减学习率），时间项在 ϵij 表达式中消去，该问题简化为一个静态线性规划，可预先求解并全程固定 αi。

### 关键技术细节
- 图模型：强连通的有向图 G=(V,E)；链路双向但权重不对称 |hij| ≠ |hji|；每个节点两台天线实现全双工。
- OAC：接收方得到邻居信号的模拟叠加，信道增益、发射功率自然形成聚合权重。
- 更新规则：DSGD + Perron 特征向量补偿：
  - 定义补偿因子 di = |Ni|，ci = (1/di)Σj∈Ni |hji|√(αjPj)；
  - 本地更新使用行随机权重 aij 构造，并采用 zii,t 补偿行随机图引起的偏差（zii,t 收敛于 πi，即 A 的左 Perron 特征向量分量）；
  - 更新规则为对 `Σj aij (xj,t + √(βj/αj) ηj,t) − γt gi,t / zii,t` 做欧氏投影。
- 证明每轮 DP 由高斯机制保证：灵敏度来自梯度裁剪上限与信道/功率系数，噪声方差来自收到叠加的高斯噪声之和。

### 关键定理
- 每轮 (ϵij,δ)-DP 的隐私上界由论文定理 1 描述，该值是**静态**的，不随轮次变化；
- 论文使用 RDP + 泊松子采样进行跨轮累积隐私核算；
- 全局收敛性由累计遗憾上界刻画：存在 U1、U2 使 E[Rj(T)] ≤ U1 + U2(1+logT)，因此平均遗憾为 O(log T/T)，即实现时间平均意义上的收敛。

## 6. 实验的主要结论与发现

- 与 PED²FL 在相同最大隐私泄漏下比较，本文提出的算法在 IID 与 non-IID、两种隐私预算下精度都更高；
- **IID 数据比 non-IID 精度高**；拓扑比较上，全连接网络 > 环形/随机图，说明高连通性有利于 DP 噪声环境下信息的传播与平均；
- **隐私与精度权衡明显**：ϵmax=0.5 时精度低于 ϵmax=1，更远低于无隐私的 ∞ 情形；
- 累积隐私泄漏方面：客户端更多时泄漏更高（固定 mini-batch 导致更大的子采样率和更弱的隐私放大）；
- 总体而言，论文认为所提算法在异构无线约束下能以 O(log T) 遗憾界收敛，并有较强工程实用性。

## 7. 优点

- **系统性建模**：把物理层无线特征（非对称信道增益、最大发射功率）与 DP 的噪声功率放在同一个框架内优化，是首个显式功率分配的无线 DP-DL 方法；
- **收敛与隐私“双证”兼备**：提供严格每轮 DP 上界、RDP 累计审计和 O(log T) 的预期遗憾界；且整体推导完整（证明在附录中逐步展开）；
- **避免双随机的强假设**：相比多数现有 DP-DL 算法，行随机矩阵更贴合实际无线广播网络；
- **常被忽略的实现细节被覆盖**：补偿系数 ci 可本地估计信道获得，无需中心协调；
- **公平对比设计**：将 PED²FL 同一隐私水平下重新运行，比较各自最优解下的精度曲线，对比逻辑合理；
- **讨论实际信道白噪声的正面作用**：指出信道噪声会降低所需 DP 注入噪声功率需求，提供了一个额外自由度。

## 8. 不足与局限

- **未报告算力及开销**：没有说明 GPU、训练时间、耗电量，这对实际可部署性的说服力有所不足；
- **收敛分析依赖强凸假设**，而神经网络环境是非凸的；作者以实验结果说明算法“实践上有效”，但理论不能直接覆盖实验对象；
- **归一化假设较强**：要求 ‖xi,t‖ ≤ √m、σi,t ≤ 1 等，限制了适用性（尽管可作为实际操作中的预处理手段）；

- **隐私定义是每轮 DP + RDP 累计**：在非常大的轮次内需要比较仔细核算；论文中训练轮次由早停准则决定，累计预算核算与早停的交互有待更谨慎的处理；
- **与 PED²FL 的比较场景单一**（仅 K=4 全连接场景），在 K=10/20 等多客户端、不同拓扑布局下未能展示相对优势或劣势；
- **缺少消融**：没有单独验证功率分配因子 LP 优化带来的性能增益，无法完全分离该机制的单项贡献；
- **应用边界**：需要全双工双天线；部分客户端设备硬件无法支持；对图强连通与时不变链路依赖较强，动态拓扑下需要另行扩展。
