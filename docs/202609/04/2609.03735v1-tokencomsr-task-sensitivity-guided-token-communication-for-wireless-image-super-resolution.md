## 摘要
对于带宽有限的衰落信道上的资源受限无线边缘设备，使用传统分离编码的无线图像传输会遭受悬崖效应的崩溃。基于卷积神经网络的流行深度联合源信道编码（JSCC）可以缓解这一问题，但通常无法保留图像块级别的结构，从而阻碍了自适应的逐令牌功率分配，并限制了超分辨率（SR）的令牌域补偿。为应对这些挑战，我们提出了一种带SR的令牌通信框架（TokenComSR）。具体而言，我们设计了一个任务敏感功率分配（TSPA）模块和一个信噪比（SNR）条件的令牌细化模块（TRM）。TSPA将任务敏感性的训练估计提取到推理令牌功率权重中，而TRM在解码前估计一个SNR条件的残差以校正令牌域中由信道引起的失真。基于TSPA和TRM，所提出的TokenComSR将基于Swin Transformer的令牌收发器与接收端SR模块配对，用于资源受限的无线图像传输。仿真结果证实了所提出的TSPA和TRM的有效性，展示了在重建保真度和感知质量方面相对于分离编码和JSCC-SR基线的改进。

## Abstract
For resource-constrained wireless edge devices over bandwidth-limited fading channels, wireless image transmission using traditional separate coding suffers from the cliff-effect collapse. Prevailing deep joint source-channel coding (JSCC) based on convolutional neural networks can mitigate this issue but usually fail to preserve patch-level structures, thereby preventing adaptive per-token power allocation and limiting token-domain compensation for super-resolution (SR). To address these challenges, we propose a token communication framework with SR (TokenComSR). Specifically, we conceive a task-sensitive power allocation (TSPA) module and a signal-to-noise ratio (SNR)-conditioned token refinement module (TRM). TSPA distills training estimates of task sensitivity into inference token power weights, while TRM estimates an SNR-conditioned residual to correct channel-induced distortion in the token domain before decoding. Building on TSPA and TRM, the proposed TokenComSR pairs a Swin Transformer-based token transceiver with a receiver-side SR module for resource-constrained wireless image transmission. Simulation results confirm the effectiveness of the proposed TSPA and TRM, demonstrating improvements over separate coding and JSCC-SR baselines in both reconstruction fidelity and perceptual quality.

## 1. 论文的核心问题与整体含义

**研究动机**
- 资源受限的边缘设备（如路边固定摄像头、传感节点）缺乏本地高分辨率图像处理能力，通常先获取低分辨率（LR）观测，再将其卸载到资源丰富的服务器侧进行高分辨率（HR）重建。这属于 6G 下云–边协同感知、通信与计算一体化场景。
- 传统分离式信源–信道编码在无线衰落信道上存在著名的**悬崖效应**：当信道 SNR 跌过设计阈值时，重建质量急剧恶化。
- 现有基于 CNN 的深度联合信源–信道编码（JSCC）虽能缓解悬崖效应，但 CNN 的特征图**缺乏对图像块级（patch-level）结构化语义的显式表达**，因而：
  - 无法支持按任务重要性进行的逐令牌（per-token）非均匀功率分配；
  - 也难以在解码前对令牌域做针对性的信道损伤校正；
  - 与下游超分辨率（SR）任务的“不同区域影响不等”的特性不匹配。

**核心问题**
> 如何在带宽受限衰落信道下，以极有限的信道使用次数（低 CBR），将低分辨率图像高效、鲁棒地传到服务器端并重建出高质量高分辨率图像？

**整体含义**
- TokenComSR 将令牌通信（TokenCom，大模型时代的语义结构化传输范式）与接收端 SR 结合，针对“边缘端算力不足、服务器端算力充足”的不对称架构，提出一套端到端可优化的无线图像超分辨率传输方案。它弥合了传输表示粒度与下游重建任务需求之间的结构错配。

## 2. 论文提出的方法论

**总体框架**
TokenComSR 采用“LR 图像 → Swin Transformer 编码器提取令牌 → TSPA 任务敏感功率分配 → 无线信道 → TRM 令牌细化 → 解码器 → SR 重建模块”的端到端流水线。核心创新集中在两大模块：TSPA 与 TRM。

### 2.1 任务敏感功率分配（TSPA）

**核心思想**
将下游 HR 重建的任务敏感度“蒸馏”成发射端的令牌级功率权重——对 HR 重建更重要（结构/纹理信息更丰富）的令牌分配更多功率，在总功率约束下提供非均匀保护。

**关键技术细节**
- 编码器将 LR 图像 ILR ∈ RH×W×3 编码为 N 个语义令牌：Z = Eϕ(ILR, ρ) = [z1, …, zN]T ∈ RN×C。
- 令牌 i 的功率系数为均值归一化形式：
  pi = N·qi / (Σj qj)，满足 Σpi/N = 1。
- qi 来自轻量 MLP 预测器：qi = softplus(gi) + ε。
- 训练阶段使用教师分支：基于 HR 域 L1 损失对令牌 zi 的一阶敏感性 si = ‖zi ⊙ ∂LHR/∂zi‖1，在固定总功率约束下可得最优分配 pi ∝ √(si + ε)，由此构造教师分布 πi = √(si+ε)/Σ√(sj+ε)。
- 预测分配分布 ˆπi = pi/N，通过 KL 散度对齐：
  Lsens = DKL(π ∥ ˆπ)。
- 教师分支仅在训练时使用（stop-gradient，截断二阶求导），推理时只用预测器输出，不增加额外开销。
- 发送前执行：能量归一化 → √pi 缩放 → 每两个实值映射为一个复数信道符号，图像码字总平均功率归一化为 1。
- 率定义相对 HR 目标图像：CBR = NC / (6r²HW)。

### 2.2 SNR 条件令牌细化模块（TRM）

**核心思想**
在解码前直接在令牌域估计信道诱导残差并修正，缓解噪声进入强非线性解码/SR 后被放大的问题。

**关键技术细节**
- 输入为接收端噪声令牌 ˆZ，首先通过线性投影获得隐藏表示 U0 = Win·Ẑ + bin。
- 经过 L=2 个 Transformer 细化块，采用 **adaLN-Zero** 设计：SNR 条件嵌入 cρ 通过 scale、shift 调制自注意力与 FFN 路径，并使用**零初始化残差门控**，使训练初始阶段 TRM 退化为恒等映射（保证初始稳定）。
- 最终输出为残差形式：Z̄ = Ẑ + Wout·Norm(UL; cρ) + bout。
- 全局自注意力可利用令牌间的上下文关系修复信道扰动造成的跨令牌关系破坏。
- TRM 的优化直接面向 SR 最终任务损失（而非监督干净令牌），因此学到的是有利于下游重建的“任务导向修复”。

### 2.3 SR 重建模块
- 解码器输出中间 LR 重建后，SR 模块由浅层特征提取层、多个堆叠的**残差 Swin Transformer 块（RSTB）**和基于像素重排（pixel shuffle）的上采样层组成，负责合成缺失的高频细节。

### 2.4 渐进式四阶段训练策略
- **阶段 1**：训练编码器、解码器和 TSPA 预测器（TRM 旁路、SR 冻结），损失以 LR L1 为主。
- **阶段 2**：解锁解码器与 TRM，逐步激活 HR 损失与感知损失；前 50 个 epoch 后线性将感知损失权重引入；λsens 在前半段为 0.05，随后线性退火到 0。
- **阶段 3**：额外解锁 SR 模块，全面联合训练。
- **阶段 4**：以阶段 3 最优模型为初值，降低学习率做全模块微调。
- 各阶段通过差异化的损失组合（LLR、LHR、VGG 感知损失 Lper、敏感性 KL 损失 Lsens）协调了链式流水线的稳定收敛。

## 6. 主要结论

- TokenComSR 在 PSNR、SSIM 与 LPIPS 上全面超越 SwinJSCC-LR、SwinJSCC-HR 与 PRAF-JSCC 基线。
- 主结果（CBR=1/8，SNR=10 dB）：
  - TokenComSR 达到 PSNR 28.23 dB、SSIM 0.8549、LPIPS 0.0872；
  - 较 SwinJSCC-LR：PSNR 提升 3.10 dB，SSIM 提升 15.66%，LPIPS 降低 57.6%；
  - 较 SwinJSCC-HR 高 1.68 dB PSNR，较 PRAF-JSCC 高 1.56 dB。
- 在不同 CBR（1/16~1/4）下始终领先最强基线 1.30–1.68 dB，优势不随带宽预算变化而消失。
- 跨数据集 ×2 在所有五个 benchmark、三个指标上均为第一；×4 时在 PSNR/SSIM 上取得四个第一、LPIPS 三个第一。
- 消融表明：TSPA 与 TRM 各自贡献一致但较小，**联合使用时感知质量增益最大**（LPIPS 降低 0.0085，其中 TRM 单独贡献 0.0057）。
- 多 K 训练使模型在 Rayleigh（K=0）至强 LoS（K=8）范围内均表现平滑提升，鲁棒性好。
- 参数量低于两个 SwinJSCC 基线（37.7 M vs 40.7/40.4 M），FLOPs 位于两者之间，说明性能增益不来自更大的模型规模。

## 7. 优点

1. **任务引导的功率分配思想新颖**：TSPA 用计算图中对 HR 损失的一阶敏感性作为“重要性教师”，通过 KL 蒸馏获得推理时仅依赖局部特征即可计算功率权重的预测器，形成“训练复杂、推理轻量”的好模式。
2. **架构与任务天然契合**：令牌与图像块的一一对应恰好为 SR（同为块级/结构级操作）提供了理想的粒度接口；选择 Swin Transformer 的收发端与基于 Swin2SR 风格的 SR 模块共享了结构先验。
3. **TRM 的 adaLN-Zero 设计工程上稳重**：零初始化门控使模块初始时恒等映射，避免训练初期信道噪声被错误强修，保证渐进式训练的可收敛性。
