## 摘要
传统链路自适应通常依赖于标量链路质量指标，如信噪比（SNR），而更丰富的信道状态信息（CSI）可以提高自适应性能，但代价是更高的处理复杂度。本文研究了一种在实时多输入多输出正交频分复用（MIMO-OFDM）系统中，利用信道频率响应（CFR）幅度描述符进行调制选择的紧凑替代方案。使用基于USRP的测试平台收集了87,817个空中（OTA）样本，并在基站（BS）侧从接收的上行导频中提取CFR测量值。评估了决策树（DT）、随机森林（RF）和k近邻（KNN）分类器，使用BS侧SNR、CFR特征及其组合。仅使用SNR的分类器测试准确率为35%-42%，而仅使用CFR特征的DT、RF和KNN分别达到73.6%、81.4%和80.0%。基于CFR的性能保持在接近10% BLER可靠性阈值，其中RF达到82.8%。进一步将深度为7的DT（123个叶子节点）集成到LabVIEW C节点中用于实时推理。结果表明，紧凑的BS侧CFR描述符比可用的标量BS侧SNR提供更具判别性的信息，同时仍适用于轻量级SDR实现。

## Abstract
Conventional link adaptation typically relies on scalar link-quality indicators such as signal-to-noise ratio (SNR), while richer channel state information (CSI) can improve adaptation at the cost of higher processing complexity. This paper investigates a compact alternative for modulation selection in a real-time multiple-input multiple-output orthogonal frequency-division multiplexing (MIMO-OFDM) system using channel frequency response (CFR) magnitude descriptors. A dataset of 87,817 over-the-air (OTA) samples is collected using a USRP-based testbed, with CFR measurements extracted at the base station (BS) from received uplink pilots. Decision tree (DT), random forest (RF), and k-nearest neighbours (KNN) classifiers are evaluated using BS-side SNR, CFR features, and their combination. SNR-only classifiers achieve 35%-42% test accuracy, whereas CFR-only features achieve 73.6%, 81.4%, and 80.0% for DT, RF, and KNN, respectively. CFR-based performance is maintained near the 10% BLER reliability thresholds, with RF reaching 82.8%. A depth-7 DT with 123 leaves is further integrated into the LabVIEW C Node for real-time inference. The results show that compact BS-side CFR descriptors provide more discriminative information than the available scalar BS-side SNR while remaining suitable for lightweight SDR implementation.

### 1. 核心问题与整体含义

- **研究动机**：传统链路自适应（Link Adaptation）通常将复杂的无线信道状态简化为标量指标（如 SNR）来进行调制与编码决策，但这种方法丢失了信道的频率选择性信息。在 MIMO-OFDM 系统中，频率选择性衰落可能使具有相似平均 SNR 的不同信道呈现出不同的可靠性，导致决策精度受限。
- **研究差距**：纯标量指标（SNR）信息量不足；而完整的复杂 CSI 虽然信息丰富，但维度高，需要复杂的模型（如 CNN-LSTM）和更大的计算开销，不利于低时延、低成本的 SDR 实时部署。

### 2. 方法论：核心思想、关键技术细节与流程

- **核心思想**：利用 TDD 信道互易性，在基站侧对上行导频进行信道估计以获得下行链路的 CFR 近似。随后，将完整的 CFR 幅度信息高度压缩为**四个统计描述符**，并作为机器学习分类器的输入特征，用于在 QPSK、16-QAM 和 64-QAM 三种调制方式之间进行决策。此举旨在用极低维的输入特征捕捉信道的核心频域特征，避开高复杂度 CSI 处理和标量 SNR 信息不充分的缺点。
- **系统架构与流程**：
    1. **信道获取**：MS 发送上行导频；BS 处理接收到的 OFDM 信号，利用 LS（最小二乘）算法估计上行 CFR。
    2. **互易性校准**：假设 TDD 互易性，通过自动校准补偿射频收发链路差异，将上行信道估计视为下行信道特征。
    3. **CFR 平滑与特征提取（关键步骤）**：在计算统计量前，先使用 **Savitzky-Golay 滤波器**对原始 CFR 幅度进行平滑降噪（多项式阶数 N=3，窗口半长 M=49，总长 99）。
    4. **特征构建（CFR 维度从 1200 个子载波压缩至 4 个描述符）**：从平滑后的 CFR 幅度中提取：
        - 均值 `|H[k]|`（反应平均信道增益）
        - 标准差 `σ|H[k]|`（反应频率选择性程度）
        - 极差（Range）`∆|H[k]|`
        - 一阶 LS 斜率（Slope）`α̂|H[k]|`（反应整体频域趋势）
    5. **分类器输入配置（对照实验设计）**：
        - `x_SNR` = 仅标量 BS 侧 SNR。
        - `x_CFR` = 仅四个 CFR 描述符。
        - `x_CFR+SNR` = 结合 CFR 描述符与 SNR。
    6. **分类器选择**：测试了三种常见的监督学习算法——决策树 (DT)、随机森林 (RF)、K近邻 (KNN)，并对比其性能与实现复杂度。
    7. **实时部署**：为了适配轻量级 SDR 硬件，将表现优秀的 DT 进行剪枝约束，最终采用**深度为 7、具有 123 个叶子节点的 DT**。工程师将其翻译为 C 语言的 if-else 规则，并集成到 LabVIEW Communications 的 C Node 中，在 BS 侧以 10 Hz 的频率进行实时推理。

### 6. 主要结论与发现

- **标量 SNR 严重限制了 BS 侧分类性能**：在测试的 3 种模型中，仅基于 SNR 的分类器的全数据测试准确率仅为 **35% – 42%**，几乎等同于或略高于随机猜测（33.3%）。说明 BS 侧分配的 SNR 与 MS 侧真实链路质量在调制分类上存在显著错位。
- **CFR 特征在调制分类中具有显著优势**：仅使用四个 CFR 幅度描述符，DT、RF、KNN 的测试准确率分别上升到 **73.6%、81.4% 和 80.0%**，极大增强了对调制类别的判别能力。
- **“CFR + SNR”组合几乎没有收益**：在 CFR 特征上叠加 BS 侧 SNR 后，RF 表现最佳达到 **82.8%（过渡区域子集）**，但整体性能相比于单独使用 CFR 的提升仅为 0.1% - 2% 不等（DT 甚至持平）——说明 CFR 描述符已经捕捉到了绝大部分可控信息，标量 SNR 带来的边际贡献几乎为零。
- **近界性能保持稳定**：对于处于 10% BLER 阈值附近的“过渡区域”测试样本，CFR-based 分类器的性能不仅没有显著下降，**RF (CFR+SNR) 甚至提高了 1.2 个百分点（达到 82.8%）**。这证明了其在实际链路切换临界区具有较强的鲁棒性和实用价值。
- **轻量级部署可行性验证**：在保证精度前提下，将高精度 RF 降级为更轻量的 DT，成功在 LabVIEW C Node 中实现了一个深度为 7 的树模型的实时推理，在 10 Hz 的实时调度约束下完成了 3 次连续相同预测才执行切换的策略，验证了 CFR + DT 的工程可落地性。

### 7. 优点

- **平衡了复杂度和性能**：开创性地在“标量 SNR（过于粗糙）”和“全量 CSI ML（过于复杂）”之间找到中间路线——以极低的特征维度换取了高比例的准确率增益，数据利用率高。
- **实验真实性**：采用**商用的 USRP-2954 硬件 + 真实 OTA 无线链路**进行实时测量，彻底摆脱了仿真假设，实验设计具有很强的工程可信度。

### 8. 不足与局限

- **信道场景限制**：仅评估了**静态、LoS、40cm 空中链路**场景。该场景属于比较容易判别的信道，密集多径（NLoS）、快速时变（移动用户）或不同距离下的信道特性会显著改变 CFR 形状，该方案在更恶劣信道下的有效性尚未论证。
- **H/W阵列条件限制**：使用的是 BS 配 14 天线的特定大规模天线阵列，验证了固定硬件配置下的场景。硬件拓扑或码本变化可能影响特征判别能力。
- **特征局限性**：只提取 CFR 幅度信息，未利用 CFR 相位信息。且分析中提及 “在目前观测条件下，代表频率选择性的统计指标（标准差、斜率）对模型的贡献不如幅度均值” ：这一可能是由于在静态 LoS 条件下信道接近平坦所致。若信道多径丰富，当前 4 特征组合的权重分配可能需要调整。
- **关于标签选择的争议**：分类标签使用的是“发送的调制方式”，而非根据实际 10% BLER 推断出的“最佳调制方式”（理论标签）。即便测试集过度集中于低阈值区域，只要发射调制标签远离真实瓶颈，分类器就无法学习到必要的分界信息。
- **资源测算不透明**：对比三种分类器，文中明确指出 RF 最好而 DT 最为轻量化，但并未提供比如推理时延、内存占用（代码段和栈大小）、能耗等**精确数值**来支撑在实际 BS 硬件上选择具体模型的定量理由。
- **算法调度策略对延迟影响**：触发切换需要连续 3 次相同预测（0.3 秒去抖），在时延极度敏感（如车联网或工业环境）下可能无法达到标准要求的 1ms 级调度响应。
- **普适性受限**：论文有公开有限条件限制的反转测试集，其 10% BLER 的阈值提取依赖于 MS 端的离线计算，虽然这不影响运行时推理，但限制了在无法获取精确下行 SNR/BLER 反馈的地域使用。
