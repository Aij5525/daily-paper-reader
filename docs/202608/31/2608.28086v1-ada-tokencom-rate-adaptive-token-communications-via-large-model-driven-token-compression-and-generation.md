## 摘要
令牌通信（TokenCom）近来作为一种新范式出现，其中令牌作为通信与计算的统一单元，实现高效的多模态语义及面向目标的传输。在本文中，我们开发了Ada-TokenCom，一种基于大型自回归模型的自适应速率令牌通信框架，它将下一令牌预测与算术编码相结合，以实现令牌级别的超低比特率语义通信。我们提出了一种混合重建/生成方案，其中发射端利用预训练的自回归大模型，在令牌序列起始处编码并传输高信息量令牌，而接收端使用相同模型预测其余部分。此外，我们设计了一种基于李雅普诺夫（Lyapunov）的算法，以动态优化信源压缩速率以及调制编码方案，适应时变网络条件。仿真结果表明，我们提出的Ada-TokenCom框架在性能上优于基于数字和深度联合信源信道编码的语义通信基线。

## Abstract
Token Communications (TokenCom) has recently emerged as a new paradigm in which tokens serve as unified units for communication and computation, enabling efficient multimodal semantic and goal-oriented transmission. In this paper, we develop Ada-TokenCom, a rate-adaptive TokenCom framework based on large autoregressive models, which integrates next-token prediction with arithmetic coding to achieve ultra-low bitrate semantic communication at the token level. We propose a mixed reconstruction/generation scheme, where the transmitter encodes and transmits the highly informative tokens at the beginning of the token sequence leveraging a pre-trained autoregressive large model, while the receiver uses an identical model to predict the rest. Moreover, we design a Lyapunov-based algorithm to dynamically optimize both the source compression rate and the modulation and coding scheme, adapting to time-varying network conditions. Simulation results demonstrate that our proposed Ada-TokenCom framework outperforms both digital and deep joint source-channel coding-based semantic communication baselines.

- **核心目标**：提出 Ada-TokenCom，一种基于大型自回归（AR）模型的速率自适应数字令牌通信框架，实现超低比特率下语义质量与通信开销的高效权衡。

## 2. 提出方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 核心思想
- **混合重构/生成机制**：将每个令牌序列划分为“头部令牌”（传输）和“尾部令牌”（接收端生成）。
  - 发射端仅对高信息量的头部令牌进行算术编码（AC）并发送；
  - 接收端用相同的预训练 AR 模型，根据已解码头部令牌和共享边信息（如类别标签/文本提示）自回归生成尾部令牌。
- **统一数字框架**：将 AR 概率建模与算术编码结合，利用条件概率实现接近自信息的无损压缩；截断长度直接控制源速率，实现灵活的速率-质量权衡。

### 2.2 关键技术细节
- **令牌化与 AR 建模**：图像经预训练 tokenizer 得到离散令牌序列 $s=[s_1,\dots,s_N]^T$；AR 模型将联合分布因子化为条件概率乘积：
  $$p(s|s_c)=\prod_{n=1}^N p(s_n|[s]_{1:n-1}, s_c)$$
  其中 $s_c$ 为边信息（如类别标签）。
- **算术编码（AC）**：使用 AR 模型输出的条件概率分布递归划分区间 $[0,1)$，将令牌序列映射为二元比特流。编码长度接近自信息 $I(s|s_c)=-\sum_n \log p(s_n|[s]_{1:n-1},s_c)$。编码过程表示为 $B_{n^*}=\psi(s_c,[s]_{1:n^*},[\Pi]_{:,1:n^*})$。
- **接收端解码与生成**：
  - 头部令牌（$n\le n^*$）通过 AC 解码精确恢复；
  - 尾部令牌（$n^*<n\le N$）由同一 AR 模型自回归预测：$\hat{s}_n=g(s_c,[\hat{s}]_{1:n-1})$。
  - 总重建过程见公式 (14)，最终经 detokenizer 得到图像 $\hat{X}$。

### 2.3 跨层速率自适应（Lyapunov 优化）
- **无线模型**：点对点准静态块衰落瑞利信道，采用 CRC、信道编码、M-QAM。
- **PER 近似**：采用瀑布阈值近似：
  $$\text{PER}_m(L,\bar\gamma)\approx 1-\exp\left(-\frac{\alpha_m\ln L+\beta_m}{\bar\gamma}\right)$$
  其中 $\alpha_m,\beta_m$ 通过离线拟合获得。
- **优化问题**：在长期平均信道符号预算 $C_{th}$ 约束下最大化时间平均语义质量（如 CLIP 相似度）：
  $$\max_{\{d_t\}} \lim_{T\to\infty}\frac1T\sum_{t=1}^T E[A_t(n_t^*)] \quad \text{s.t.} \lim_{T\to\infty}\frac1T\sum_{t=1}^T E[\bar{C}_t(d_t,\bar\gamma_t)] \le C_{th}$$
- **虚拟队列与 drift-plus-penalty**：定义虚拟队列 $Z_{t+1}=\max\{Z_t+\bar{C}_t-C_{th},0\}$，每时隙求解：
  $$d_t^*=\arg\min_{d_t\in\mathcal{D}}\{Z_t\bar{C}_t(d_t,\bar\gamma_t)-\eta A_t(n_t^*)\}$$
  其中 $\eta>0$ 平衡语义质量与资源消耗。该算法复杂度为 $O(|\mathcal{D}|)=O(|N||M|)$，无需未来信道信息。

## 6. 主要结论与发现

- AR 条件自信息随令牌位置递减：早期令牌信息量更高，尾部令牌更可预测，支持“传头、生成尾”策略。

- 在无线场景下，Ada-TokenCom 在低 CBR 区域相比 SwinJSCC 在 CLIP 上提升约 21%–47%（不同 SNR），LPIPS 降低最多约 60%，FID 降低最多约 77%；但 SwinJSCC 在 PSNR 上更高（像素级保真优势）。
- Lyapunov 自适应可在不依赖未来信道信息的情况下接近 long-term oracle 的累计语义质量，同时满足长期预算；固定策略（短截断过于保守、长截断违反预算）均不如自适应策略。
- 框架将模型训练与信道适配解耦，无需为每个数据集重新端到端训练，提高了跨应用复用性。
