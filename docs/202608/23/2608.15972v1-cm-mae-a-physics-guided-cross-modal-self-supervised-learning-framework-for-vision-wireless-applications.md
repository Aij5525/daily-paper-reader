## 摘要
同步的相机和无线测量通过不同的物理信道观察同一场景。核心困难在于，在一个部署环境中学习的表示在视点、交通、照明和传播几何变化时可能会失效。本文提出了CM-MAE，一种用于跨场景表示迁移的自监督视觉-无线预训练框架。所评估的真实数据模型仅使用RGB帧和DeepSense 6G中可用的测量64波束接收功率向量；在预训练期间不使用射线追踪路径、校准深度或波束索引标签。其核心预训练项是软对比对齐损失。该损失不是将同步的图像-无线对作为唯一的正样本对，而是根据测量的波束功率轮廓之间的相似性构建目标分布，从而不会将具有相似方向响应的非相同样本强制分离为假负样本。掩码联合解码器通过在模态丢失下重建隐藏的视觉补丁和无线角度聚类，提供了互补的局部目标。预训练后，差分速率微调规则允许新的融合头快速适应，同时编码器缓慢更新。在序列不重叠的DeepSense 6G协议下，添加软对齐损失将匹配的线性探针迁移平均值从24.88%提高到29.49%。轻度融合微调在未见过的场景6-8上达到77.38%的Top-1准确率，可选的直推归一化适应达到78.69%。由于融合设置在推断时使用同期64波束功率向量，这些结果应被视为表示迁移的诊断，而非主动波束预测或减少扫描的声明。

## Abstract
Synchronized camera and wireless measurements observe the same scene through different physical channels. The central difficulty is that a representation learned in one deployment can fail when viewpoint, traffic, illumination, and propagation geometry change. This paper presents CM-MAE, a self-supervised vision--wireless pretraining framework for cross-scenario representation transfer. The evaluated real-data model uses only RGB frames and the measured 64-beam received-power vector available in DeepSense 6G; it does not use ray-traced paths, calibrated depth, or beam-index labels during pretraining. Its central pretraining term is a \emph{soft contrastive alignment loss}. Instead of making the synchronized image--wireless pair the only positive pair, this loss builds a target distribution from similarities between measured beam-power profiles, so nonidentical samples with similar directional responses are not forced apart as false negatives. A masked joint decoder provides the complementary local objective by reconstructing hidden visual patches and wireless angular clusters under modality dropout. After pretraining, a differential-rate fine-tuning rule lets a new fusion head adapt quickly while the encoders move slowly. Under a sequence-disjoint DeepSense 6G protocol, adding the soft alignment loss improves a matched linear-probe transfer average from 24.88\% to 29.49\%. Mild fusion fine-tuning reaches 77.38\% Top-1 accuracy on unseen Scenarios 6--8, and optional transductive normalization adaptation reaches 78.69\%. Since the fusion setting uses the contemporaneous 64-beam power vector at inference, these results should be read as representation-transfer diagnostics, not as proactive beam-prediction or reduced-sweeping claims.

- **整体含义**：论文提出 CM-MAE（Cross-Modal Masked Autoencoder），一个物理引导的跨模态自监督预训练框架。其核心是**用波束功率轮廓相似性构造软对比对齐目标**，避免把物理上相近的样本当作假负样本；并配合**遮蔽联合解码器**进行局部重建。实验证明该方法在 DeepSense 6G 跨场景迁移任务上显著优于已有基线。

## 2. 论文提出的方法论

### 2.1 总体框架

- 双流 Transformer 编码器：一个视觉分支处理 RGB 图像补丁，一个无线分支处理 64 维波束功率向量提取的稀疏角度簇。
- 全局目标：**软对比对齐损失**，将学习到的跨模态检索分布匹配到测量波束轮廓定义的邻域分布。
- 局部目标：**遮蔽联合解码器**，在模态缺失情况下重建隐藏的视觉补丁与无线角度簇。
- 下游阶段采用**差分速率微调**：新融合头快速适应，预训练编码器缓慢更新。

### 2.2 关键设计细节

- **视觉 token 化**：图像分为 \(P\) 个补丁，每个补丁加入可学习位置编码和由相机内参计算的归一化射线方向 \(d_p=K_{\text{cam}}^{-1}\tilde{e}_p/\|K_{\text{cam}}^{-1}\tilde{e}_p\|_2\)。该射线只是图像平面方向坐标，不是深度估计或路径标签。
- **无线 token 化**：
  - 将 64 波束功率转为 dB 并按样本 min-max 归一化到 \([0,1]\)，同时保留绝对功率最大值作为“尺度 token”。
  - 从归一化功率谱中检测局部峰值（阈值 \(\eta=0.15\)），最多保留 \(Q_{\max}=10\) 个角度簇；用局部功率加权质心表示簇位置。
  - 每个簇 token 包含局部功率形状、峰值质量指示和傅里叶角度编码。
- **软对比对齐损失**：
  - 对批次中样本 \(i,j\)，用归一化功率轮廓的内积定义距离 \(d_{ij}\)，再通过高斯核构造非自身样本的软目标 \(q_{ij}\)。
  - 视觉到无线、无线到视觉两个方向的检索分布 \(\pi^{v\to w}_{ij}\) 用 CLS 嵌入的余弦相似度加温度 \(\tau=0.07\) 的 softmax 计算。
  - 损失为 \(L_{\text{ctr}}=-\frac{1}{2B}\sum_{i,j}q_{ij}(\log\pi^{v\to w}_{ij}+\log\pi^{w\to v}_{ij})\)，等价于 KL 散度匹配，因此是“分布匹配”而非“多正样本二元对比损失”。
- **遮蔽与重建**：
  - 图像掩码率 \(r_v=0.75\)，使用连续 \(4\times1\) 块掩码；无线簇掩码率 \(r_w=0.5\)。
  - 被掩码位置保留坐标/位置信息，只替换内容为可学习的 mask token。
  - 联合解码器同时接收两个模态的编码序列，分别重建视觉补丁向量与无线簇特征。
  - 模态 dropout 概率 \(p_{\text{md}}=0.1\)，当某一分支缺失时，对应重建项保留、对齐项关闭。
- **预训练总损失**：\(L_{\text{pre}}=a_v L_{\text{rec},v}+a_w\beta_w L_{\text{rec},w}+a_v a_w \lambda_{\text{ctr}}L_{\text{ctr}}\)，其中 \(\lambda_{\text{ctr}}=0.2\)。

### 2.3 微调与测试时适应

- **Mild fine-tuning**：编码器学习率 \(\eta_e=3\times10^{-6}\)，融合头学习率 \(\eta_h=10^{-3}\)，两者相差约 333 倍。采用 AdamW、余弦衰减、标签平滑等设置。
- **可选 TTA**：仅更新归一化层仿射参数，最小化未标注目标批次预测熵，作为直推式（transductive）结果单独报告。

## 6. 论文的主要结论与发现

- **软对齐损失有效**：在序列不相交协议下，将线性探针迁移平均从 24.88% 提升到 29.49%。
- **轻度微调显著优于全量微调**：全量微调在 Sc6–8 上仅 51.36%，轻度微调达到 77.38%，说明“如何适应预训练模型”与“预训练本身”同等重要。
- **融合是必要的**：视觉-only 与 CSI-only 的跨场景平均分别只有 29.60% 和 35.06%，融合后达到 77.38%，证明两种模态互补。
- **掩码重建的作用在微调阶段显现**：冻结线性探针下 CLS-SoftCtr 更高（38.14% vs 31.71%），但轻度微调后 CM-MAE-U 反超（45.04% vs 37.34%），说明局部重建作为正则化项在适应时发挥作用。
- **软目标优于硬目标**：在“无掩码”和“有掩码”两种设置下，软对比对齐都比硬 InfoNCE 高约 2.6 和 5.9 个百分点。
- **TTA 可进一步提升**：轻度微调 + TTA 在 Sc6–8 平均达 78.69%，对最难场景提升最明显。
- **掩码率存在最优区间**：视觉掩码率 0.75 优于 0.5 和 0.9；无线簇掩码率 0.75 严重损害迁移性能。
- **Sc5 高准确率具有误导性**：由于与训练场景视觉域接近，不能作为跨场景泛化的代理指标。

## 7. 优点

- **问题定位清晰**：明确区分“预训练输入”与“下游波束索引标签”，避免标签泄漏。
- **物理引导的软目标设计**：用测量波束功率轮廓的相似性而非样本身份定义正负关系，缓解了毫米波波束响应中大量样本方向响应相近导致的假负样本问题。
- **损失函数可解释**：软对比对齐被严格推导为 KL 散度匹配，具有明确的分布匹配含义。
- **模块化消融设计**：从预训练目标、微调策略、掩码设计三个层面分别分析，归因清晰。
- **诚实的实验边界**：明确声明融合推断使用同期功率向量，不夸大为主动预测；明确区分 source-only 与 TTA 结果。
- **对失败尝试透明**：报告了域对抗不稳定、继续预训练退化等负面结果，增加了方法论的可信度。

## 8. 不足与局限

- **未使用路径级对应**：对齐只在样本级 CLS token 上进行，未实现图像补丁与波束簇之间的细粒度对应；论文将其列为未来工作。
- **缺乏时间建模**：模型为单帧单快照，未利用短时图像-CSI 序列来应对瞬时遮挡。
- **依赖同期功率向量**：下游推断需要已完成的 64 波束扫描，因此不能直接用于减少波束扫描开销或主动预测。
- **模型规模较大**：约 2.32 亿参数的双流 ViT-Base，部署成本高，论文未给出蒸馏方案。
- **预训练数据规模有限**：仅在 DeepSense 6G Sc1–5 上预训练 160 epochs，尚不能证明通用基础模型能力。
- **模态 dropout 的增益未被实验证实**：在冻结线性探针下，无 dropout 反而更高，作者把它作为鲁棒性设计保留，但缺少显式缺失模态测试。
- **TTA 是直推式设置**：需要未标注目标批次，并非 source-only 零样本适应。
- **外部验证不足**：论文自身提出需要在隐藏测试集上进一步评估，当前结果主要基于自建协议。
