## 摘要
通过监督式思维链微调和基于可验证奖励的强化学习进行后训练，已显著提升了大语言模型（LLM）的数学推理能力。然而，这些方法在信号处理问题上的应用仍相对不足。本报告研究了针对WirelessMATHBench-XL（该领域数学推理的综合基准）中的研究生级信号数学问题，对Qwen2.5-3B-Base进行强化微调的策略。我们考察了两种训练范式：（i）在WirelessMATHBench-XL上使用可验证奖励的直接强化学习（RL）；以及（ii）在蒸馏的无线领域思维链语料库上进行监督式微调（SFT），随后进行相同的领域特定RL阶段。在这两种范式中，我们对组相对策略优化（GRPO）、组序列策略优化（GSPO）和几何平均策略优化（GMPO）进行了基准测试。我们旨在评估领域感知的CoT SFT是否可作为后续RL的有效初始化，以及GSPO或GMPO在信号推理任务中相对于GRPO是否在稳定性或准确性方面具有优势。我们最好的模型实现了39.12%的总体准确率，相比未训练的Base模型（12.37%）提升超过三倍。

## Abstract
Post-training with supervised chain-of-thought fine-tuning and reinforcement learning from verifiable rewards has substantially improved the mathematical reasoning capabilities of large language models (LLMs). However, their application to signal processing problems remains relatively under-explored. This report investigates reinforcement fine-tuning strategies for adapting Qwen2.5-3B-Base to graduate-level signal mathematical problems from WirelessMATHBench-XL, a comprehensive benchmark for mathematical reasoning in this domain. We examine two training paradigms: (i) direct reinforcement learning (RL) on WirelessMATHBench-XL with verifiable rewards; and (ii) supervised fine-tuning (SFT) on a distilled wireless-domain chain-of-thought corpus, followed by the same domain-specific RL stage. Across both paradigms, we benchmark Group Relative Policy Optimization (GRPO), Group Sequence Policy Optimization (GSPO), and Geometric-Mean Policy Optimization (GMPO). We aim to assess whether domain-aware CoT SFT serves as an effective initialization for subsequent RL, and whether GSPO or GMPO offer advantages in stability or accuracy over GRPO for signal reasoning tasks. Our best model achieves an overall accuracy of 39.12\%, representing a more than threefold improvement over the untrained Base model (12.37\%).

## 2. 方法论：核心思想、关键技术细节、算法流程

### 2.1 总体框架
- 论文提出两种训练路线（图 4）：
  - **Route A（直接 RL）**：从 Qwen2.5-3B-Base 出发，直接在 WirelessMATHBench-XL 上使用可验证奖励进行强化学习，不经过任何 SFT。
  - **Route B（SFT + RL）**：先在 Wireless-CoT-Mix 语料上做监督微调，再在同一基准上执行相同的 RL 阶段。

### 2.2 监督微调（SFT）
- 使用标准自回归负对数似然损失训练。
- 语料为 Wireless-CoT-Mix，包含 3,542 个样本：
  - 1,546 个无线领域问题-推理对（由 DeepSeek-V3 蒸馏，经过答案校验和长度过滤）。
  - 1,996 个从 NuminaMath-CoT 采样的通用数学推理样本。
- 目的是初始化模型的领域推理行为、数学分解习惯和最终答案格式。

### 2.3 三种 RL 算法

- **GRPO（Group Relative Policy Optimization）**：
  - 摒弃 PPO 中的批评网络，每个 prompt 采样 G 个响应，对组内奖励做归一化得到优势估计：
    - Âᵢ = (rᵢ − mean({rⱼ})) / (std({rⱼ}) + ε)
  - 使用 token 级重要性比率的裁剪目标，配合 KL 惩罚项。
  - 优点：节省内存、对奖励尺度不敏感、组均值作为隐式基线。

- **GSPO（Group Sequence Policy Optimization）**：
  - 指出 GRPO 的 token 级重要性采样是病态的——奖励只作用于整个序列时，token 级 off-policy 修正引入高方差噪声，可能导致模型崩溃。
  - 将优化单元从 token 提升到**完整序列**，使用长度归一化的序列级重要性比率：
    - sᵢ(θ) = [πθ(yᵢ|x) / πθ_old(yᵢ|x)]^(1/|yᵢ|)
  - 在序列层面对 sᵢ(θ) 进行裁剪，与奖励粒度对齐。

- **GMPO（Geometric-Mean Policy Optimization）**：
  - 针对 GRPO 中 token 级比值被算术平均可能受极端值主导的问题，改用**几何平均**聚合。
  - 由于 AM–GM 不等式，GMPO 目标的值域更窄，优化方差更低。
  - 在 log 空间对个体 token 比值做裁剪（剪辑范围更宽，受 DAPO Clip-Higher 启发），保留未裁剪 token 的梯度信号。
  - 优点：降低对异常比值 token 的敏感性，提高训练稳定性，同时保留更细粒度的优化信号。

### 2.4 奖励函数设计
- 从模型响应中提取所有 `\boxed{}` 表达式，与真实答案逐项匹配，奖励分四档：
  - 未检测到 boxed → 0.0
  - m = 0（没有匹配） → 0.1
  - 0 < m < M（部分匹配） → 0.2
  - m = M（全部匹配） → 1.0
- 该奖励仅关注最终答案是否正确，不评价中间推导过程。

## 6. 主要结论与发现

- **RL 显著提升性能**：
  - Base 模型整体准确率仅 12.37%，经过 RL 后所有变体提升至 34.38%–39.12%，提升超过三倍。
- **SFT 本身有效，且与算法相关**：
  - 单独 SFT 将准确率提升至 28.75%，说明蒸馏的无线领域 CoT 有用。
  - SFT+RL 对 GSPO 和 GMPO 帮助明显（B-GSPO 37.75%，B-GMPO 39.12%）；但对 GRPO 帮助不明显（A-GRPO 34.50% vs B-GRPO 34.38%），说明 GRPO 的 token 级优化对初始化质量不敏感。
- **GSPO/GMPO 优于 GRPO**：
  - 在准确率、收敛速度、训练稳定性方面均优于 GRPO；GMPO 在 SFT 后取得最佳整体性能（39.12%）。
- **推理缩短现象**：
  - GRPO 变体输出约 545–668 token，而 GSPO/GMPO 变体输出仅 243–396 token，且准确率相当或更高。
  - 该现象被解释为模型学习到“直接输出答案”的捷径：奖励只检查最终 boxed 答案，不奖励中间推导。
- **SFT 过训问题**：
  - 使用最终 SFT checkpoint 做 RL 反而效果更差，原因可能是过拟合 SFT 分布导致策略熵降低，限制 RL 探索；因此采用了中间 checkpoint。
- **对更广泛模型的启示**：
  - 3B 模型经领域化后处理无线数学问题仍有明显上限（39.12% vs 强模型 57%+），但与 7B 甚至 27B 通用模型（Qwen2.5-7B 25.75%、Gemma 3 27B 31.50%）相比已具竞争力。

## 7. 优点

1. **选题有针对性**：信号数学推理是一个尚未被小模型后训练充分探索的领域，论文填补了空白。
2. **实验设计清晰**：双路线（直接 RL vs SFT+RL）与三算法（GRPO/GSPO/GMPO）的组合矩阵，干净地分离了“初始化质量”和“优化算法”两个变量。
3. **对异常现象有深层分析**：不仅报告“推理缩短”，还从 GSPO 的序列级惩罚、GMPO 的几何均值特性、SFT 先验和奖励函数设计四个角度给出了机制解释，而不是简单描述现象。
4. **实用工程细节丰富**：包括 MCQ 答案格式修正、tokenizer EOS 替换、SFT 中间 checkpoint 选取等，对复现非常有价值。
5. **在极小算力下完成研究**：仅 3 张 RTX 4090 就训练了全部模型，说明该研究路径对普通实验室可行，具有很高复现性价比。
6. **结果透明**：报告了输出 token 长度、训练曲线、SFT 损失曲线等，有助于评估效率和稳定性。

## 8. 不足与局限

1. **单次运行，缺乏统计显著性验证**：所有实验似乎只运行一次，未报告多次运行的均值和方差，无法确定算法间差异是否显著。
2. **奖励函数只检查最终答案**：将正确推理与单纯答案匹配混为一谈，导致“推理缩短”虽然被指出，但并未被当作缺陷修复；准确率的提升不能代表真实推理能力提升。
3. **SFT 中间 checkpoint 选择标准不明确**：论文指出最终 checkpoint 会损害 RL 效果，但没有系统搜索选择中间 checkpoint 的规则，可能导致结果依赖人工经验。
4. **外部模型对比公平性受限**：没有详细说明外部模型的推理设置（温度、采样、提示等），并且外部模型结果可能来自原 benchmark 论文，未做统一评测，存在设置差异风险。
5. **未扩展到更大规模模型**：方法在 3B 模型上有效，但未验证是否对 0.5B、1B 或 7B 同样成立，缺少规模泛化证据。
6. **缺乏消融实验**：未分析 SFT 语料中无线部分与通用部分的比例影响，也未验证奖励函数分档（0.1/0.2）的具体效果，难以判断每个设计选择的独立贡献。
7. **“上限”含义有限**：标题声称评估 3B 模型上限，但实验只覆盖了三种 RL 变体和一组超参数，未尝试更大的 group size、更长的训练步数或更优的奖励设计，因此“上限”应理解为在给定配置下的性能，而非理论或实际可达的最高性能。
