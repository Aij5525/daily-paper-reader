## 摘要
我们提出了一种集成感知与通信（ISAC）波束赋形方法，可同时执行多输入多输出（MIMO）雷达感知和多用户MIMO通信。我们的方法建立在MIMO雷达问题的矩阵邻近公式之上，并利用我们最近提出的高效求解器，其计算复杂度主要由每次迭代中的特征值分解（EVD）评估决定。我们通过加入最小信噪比约束作为通信设计准则，将该公式扩展到ISAC场景，仅需基站处的统计信道状态信息。此外，我们提出了一种方法来避免某些迭代中繁重的EVD评估，在大规模MIMO设置下将计算时间最多减少六倍。

## Abstract
We propose an integrated sensing and communication (ISAC) beamforming method that performs joint multiple-input multiple-output (MIMO) radar sensing and multi-user MIMO communication. Our approach builds on a matrix nearness formulation of the MIMO radar problem and utilizes our recently proposed efficient solver, where the computational complexity is dominated by an eigenvalue decomposition (EVD) evaluation at each iteration. We extend this formulation to an ISAC scenario by incorporating minimum signal-to-noise ratio constraints as communication design criteria, only requiring statistical channel state information knowledge at base station. Furthermore, we propose a method to avoid the burdensome EVD evaluations in certain iterations, reducing the computation time by up to six times in a massive MIMO setting.

- **核心问题**：在集成感知与通信（ISAC）系统中，如何高效设计联合MIMO雷达感知与多用户MIMO（MU-MIMO）通信的发射波束赋形矩阵。现有方法面临两大瓶颈：

- **研究含义**：本文致力于提出一种**仅需统计CSI**（信道协方差矩阵）、**计算高效**、且能**同时满足通信服务质量（QoS）与雷达感知性能**的长期波束赋形方案，以推动ISAC技术在大规模MIMO系统中的实际落地。

## 2. 论文提出的方法论：核心思想、关键技术与算法流程

**核心思想（方法概述）：**
- 基于作者前期提出的**矩阵邻近（Matrix Nearness）公式**，将MIMO雷达波束赋形问题转化为最小化发射协方差矩阵R与理想矩阵 T̃ 之间Frobenius范数距离的凸优化问题；
- 在此基础上，**新增通信用户的最小SNR约束**，将纯感知问题扩展为ISAC联合设计问题；
- 利用对偶理论求解该凸问题，并在迭代求解过程中提出**条件化加速策略**（基于Courant-Fischer定理），跳过无需计算的特征值分解（EVD），从而显著降低计算代价。

**关键技术细节：**

1. **感知目标建模**：
   - 波束方向图：P(φ) = a_T^H(φ) R a_T(φ)；
   - 理想波束方向图矩阵T：主瓣区域设为1，旁瓣区设为ε；
   - 矩阵邻近成本函数：J_s(R) = ∥D^H R D − ηT∥_F²，在均匀采样电角域的ULA条件下可化简为：J_s(R) = ∥R − T̃∥_F² + C，其中 T̃ = η D D^H。

2. **通信目标建模**：
   - 第 i 个用户的SNR表示为：SNR_i = Tr(Ω_i R) / (σ_i² M_R)，其中 Ω_i = E[H_i^H H_i] 为信道协方差矩阵（仅需统计CSI）；
   - 通信约束形式化为线性不等式：Tr(Ω_i R) ≥ Γ_i。

3. **联合优化问题（式(12)）**：
   - 目标函数：min (1/2)∥R − T̃∥_F²
   - 约束条件：通信SNR约束（11）＋每根天线等功率约束 Tr(E_j R) = P_T/M_T ＋半正定约束 R ⪰ 0；
   - 这是一个**凸优化问题**，可通过拉格朗日对偶理论求得全局最优解。

4. **求解算法（Algorithm 1）**：
   - 采用加速投影梯度法，配合**自适应动量重启**策略；
   - 每次迭代的核心运算为投影运算 [M]₊ = Σᵢ(λᵢ)₊ qᵢqᵢ^H，即对 Hermitian 矩阵做**特征值分解（EVD）**并保留正特征值部分；
   - 对偶变量的梯度更新需要反复调用该投影，EVD成为计算瓶颈（复杂度 O(M_T³)）。

5. **加速策略（核心创新之一）**：
   - 利用**Courant-Fischer定理**中的不等式 λ_min(A₁ + A₂) ≥ λ_min(A₁) + λ_min(A₂)，推导出投影输入矩阵已经半正定的**充分条件**（式(24)）：
     - λ_min(T̃) − max_j μ̄_kj + Σᵢ ν̄_ki λ_min(Ω_i) ≥ 0
   - 当该条件满足时，可**直接跳过EVD计算**，令投影结果等于输入矩阵本身；
   - 注意 λ_min(T̃) 和 λ_min(Ω_i) 只需预先计算一次，不增加迭代复杂度。

**算法流程（文字说明）：**
- 初始化对偶变量ν、μ及其动量项，设置迭代计数；
- 在每轮迭代中：① 计算加速动量插值 μ̄、ν̄；② 构造矩阵 (T̃ − B(μ̄) + C(ν̄))；③ 判断式(24)是否成立——若成立则跳过EVD直接得到投影结果；否则执行完整EVD投影；④ 更新对偶变量并检查重启条件；⑤ 检查收敛条件（Δ≤ε），满足则输出最优对偶变量，进而恢复最优协方差矩阵 R⋆。

## 6. 论文的主要结论与发现

1. **感知-通信存在固有折中**：随着通信SNR要求提高（Γ̃从10 dB到25 dB），感知主瓣功率占比 P_m/P_T 降低、PSL升高，即感知性能系统性下降，符合功率资源竞争的理论预期。
2. **波束图形态自适应调整**：在SNR要求较高时（25 dB），波束图在用户LoS方向形成明显波峰；若用户位于感知主瓣区域（如0°用户），通信约束与该区域感知功率自然重合，无需额外功率分配。
3. **加速方法效果显著**：
   - 当SNR要求较低（Γ̃ ≤ 15 dB）时，C-Alg. 1可**完全避免**所有EVD计算，计算时间仅约2秒，相比非加速版本（约13–15秒）**降低约6倍**；
   - 当SNR要求较高时（17.5–25 dB），加速效果有所减弱（可避免11%–30%的EVD计算），但**始终能够减少计算开销**；
   - 条件(24)在仿真中成功捕获了所有可省略EVD的情况（零误判）。
4. **通用求解器不可行**：在M_T=128、N_φ=2048的规模下，CVXPY+Clarabel因内存消耗过大而失败，凸显了所提定制算法在实践中的不可替代性。

## 8. 不足与局限

- **实验场景单一**：仅验证了单个感知主瓣和5个用户的特定配置；多目标感知、不同用户密度、不同天线规模（如超大规模MIMO M_T≥256）等场景未覆盖。
- **未考虑多用户干扰**：SNR模型中明确假设多用户干扰在后续波形设计阶段处理（文中脚注），未在协方差设计层面显式抑制用户间干扰，在用户密集场景下可能造成实际通信性能下降。
- **统计CSI准确性依赖**：方法假设基站已知准确的信道协方差矩阵Ω_i，但在实际系统中统计CSI的估计误差会如何影响最优性未被讨论。
- **加速条件为充分非必要**：条件(24)是判定投影可跳过的充分条件而非必要条件，意味着实际可跳过的EVD次数可能多于当前方法检测到的次数——加速效果仍有进一步提升空间。
- **硬件普适性未验证**：仅在特定CPU上测试，未分析不同平台下的扩展性（如ARM架构、专用加速硬件）。
- **与现有ISAC方案的直接对比不足**：缺乏与其他ISAC波束赋形方法（如SDR方法、交替优化等）在感知质量与通信QoS层面的系统对比，难以从绝对意义上评估其性能优劣。
