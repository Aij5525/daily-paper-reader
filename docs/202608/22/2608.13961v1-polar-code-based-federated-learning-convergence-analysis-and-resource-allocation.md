## 摘要
联邦学习（FL）能够在分布式设备间协作训练模型而无需共享原始数据，然而在实际中面临显著的通信瓶颈和信道损伤。传统的网络层处理方法要么将信道理想化为无差错，要么对传输的模型更新施加等差错保护（EEP），未能考虑单个局部模型内量化比特固有的不等重要性。为解决这一局限，我们提出一种基于极化码的跨层联邦学习方案，利用有限分组长度下极化码的不等差错保护（UEP）特性。具体而言，所提设计选择性地保护更重要的量化比特，从而减轻信道噪声的不利影响。我们进一步对所提方案进行了严格的收敛分析，推导出收敛差距的上界，并在所有训练迭代中联合优化量化比特数和极化码分组长度。实验结果表明，我们基于极化码的方案在恒定和可变分组长度配置下，均持续比未编码和基于LDPC的EEP基准取得显著的性能提升，且随着信道质量恶化，优势愈发明显。这些发现证实了我们的跨层设计在现实信道条件下增强联邦学习鲁棒性和有效性的作用。

## Abstract
Federated learning (FL) enables collaborative model training across distributed devices without sharing raw data; however, it faces significant communication bottlenecks and channel impairments in practice. Conventional network layer treatments either idealize the channel as error free or apply equal error protection (EEP) to transmitted model updates, failing to account for the inherently unequal importance of quantization bits within a single local model. To address this limitation, we propose a cross layer polar code based FL scheme that leverages the unequal error protection (UEP) property of polar codes under finite block lengths. Specifically, the proposed design selectively protects more significant quantization bits, thereby mitigating the detrimental effects of channel noise. We further provide a rigorous convergence analysis of the proposed scheme, deriving an upper bound on the convergence gap, which we then jointly optimize over the number of quantization bits and the polar code block length across all training iterations. Experimental results demonstrate that both constant and variable block length configurations of our polar code based scheme consistently achieve substantial performance gains over uncoded and LDPC-based EEP benchmarks, with the advantage becoming increasingly pronounced as the channel quality deteriorating. These findings confirm the efficacy of our cross-layer design in enhancing FL robustness and efficiency under realistic channel conditions.

### 2. 方法论：核心思想、关键技术细节与流程

#### 2.1 核心思想
- 利用极化码在有限块长下合成信道质量不一致（Bhattacharyya参数不同）的特性，构建UEP机制。
- 将局部梯度先进行**无偏随机量化**，量化后的每个分量由多个比特表示，各比特的量化区间宽度不同，因此重要性不同（高比特位代表更大的量化区间）。
- 将重要性较高的比特映射到极化码中更可靠的合成信道上，重要性较低的比特映射到较不可靠的信道上，从而实现UEP。
- 在接收端采用“软输出补偿”方法，用Bhattacharyya参数作为信道输出调整因子，消除由解码错误引入的偏置。

#### 2.2 系统模型
- 系统包含M个用户和1个服务器，每轮随机选择K个用户参与训练。
- 传输信道为**二进制擦除信道（BEC(ϵ)）**，擦除概率为ϵ。
- 用户本地用SGD更新，但传输的是梯度 `g_{k}^{t+1}` 而非模型参数，服务器对接收到的（受信道噪声和量化影响的）梯度进行聚合更新。

#### 2.3 量化与编码联合设计
- **无偏量化**：每个梯度分量用n个比特表示，量化电平均匀分布在[B_min, B_max]上，采用随机取整保证无偏性（Lemma 1）。
- **极化码UEP映射**：
  - 对块长N的极化码，计算各合成信道的Bhattacharyya参数 `Z(W_N^{(i)})`，并按升序排列（i越小越可靠）。
  - 将量化后的第l个比特（l=1,...,n）放入第l个最可靠的合成信道，剩余N-n个信道作为冻结比特。
  - 比特错误概率有上界：`P_l ≤ Z(W_N^{(l)})`。
- **软输出补偿**：定义 `\bar{B}_l = \hat{B}_l + (1-2\hat{B}_l)Z_l`，其中`Z_l = Z(W_N^{(l)})`，使重构误差的期望为零（证明E[Δ] = 0）。

#### 2.4 收敛分析（Theorem 1）
- 在标准假设（L-光滑、μ-强凸、梯度无偏、梯度界、方差界）下，推导出收敛上界：
  \[
  E[F(w_T)-F^*] \le \frac{L}{2}\left(\prod_{t=1}^T(1-\mu \eta_t)\right)E\|w_0-w^*\|^2 + \frac{L}{2}\sum_{t=1}^T \left(\prod_{j=t+1}^T(1-\mu \eta_j)\right)\eta_t^2 H
  \]
- 其中H包含：
  - SGD噪声项 `4G^2`
  - 数据异质性项 `4LΓ`
  - 随机梯度方差项
  - **传输损失**：`d\Delta^2 \sum_{i=1}^n 4^{i-1} Z(W_N^{(i)})`
  - **量化误差**：`d\Delta^2/6`
  - **用户调度损失**：`(M-K)G^2/(K(M-1))`
- 结论：增加块长N会减小Bhattacharyya参数，增加量化比特n会减小量化间隔Δ，两者均能减少最优性差距。

#### 2.5 资源分配优化（第V节）
- 观察：越到后期，因子 `\prod_{j=t+1}^T(1-\mu \eta_j)` 越小，因此后期的噪声项对累计误差贡献更大，应当后期分配更多资源（更长块长）。
- 由于Bhattacharyya参数无闭式表达式，**用高斯CDF近似**：`γ(x)=0.5*erf((x-μ)/σ)+0.5`，其中μ和σ拟合为块长N的线性函数，参数取决于ϵ（表I、II）。
- 优化问题P1：在总通道使用预算 `Σ N_t ≤ T·N_ave` 和块长限制 `N_t ∈ {16,32,64,128}`下，最小化传输损失 + 量化损失之和。
  - **第一步：固定N_t，优化n_t**。发现最优n_t仅依赖ϵ，不依赖N_t和t（表III给出“good”n的范围，如ϵ=0.6时n=4）。
  - **第二步：固定n，优化N_t**。转化为混合整数非线性规划（MINLP），用粒子群优化（PSO）求解。
- 实验结果显示变块长方案（后期分配更长块长）比固定块长（N=16）的收敛上界更低，且按通道使用次数看收敛更快。

### 6. 主要结论与发现

1. **所提方案有效**：基于极化码UEP的FL传输方案，在恒长和变长块长配置下，测试准确率和收敛速度均明显优于未编码和LDPC-EEP方案。

4. **理论指导**：收敛上界表明传输损失项与Bhattacharyya参数和量化间隔相关，资源分配优化可有效降低上界，且“后期分配更多资源”符合理论预期。
5. **极化码UEP优于LDPC-EEP**：证明对量化比特的重要性感知保护是关键，而非仅仅使用强纠错码。
