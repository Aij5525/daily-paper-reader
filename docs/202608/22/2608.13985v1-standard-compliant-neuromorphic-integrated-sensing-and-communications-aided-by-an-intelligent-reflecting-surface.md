## 摘要
神经形态计算能够实现事件驱动的低功耗推理，因此在资源受限的无线设备上联合执行通信、感知和处理是一项有吸引力的技术。脉冲无线电超宽带（IR-UWB）信号在IEEE 802.15.4系列中标准化，并广泛用于测距和短距离通信，它与神经形态处理自然匹配，因为两者都通过稀疏的时间事件或尖峰进行操作。在此背景下，本文研究了一种符合标准的神经形态集成传感与通信（N-ISAC）系统，其中单个尖峰神经网络（SNN）接收机直接从通用的IEEE 802.15.4z高重复频率（HRP）UWB波形中联合解调数字数据并检测无源雷达目标。与先前假设基本脉冲位置调制接口和简化多径信道的N-ISAC工作不同，我们考虑完整的标准化物理层以及由可重构智能表面（RIS）辅助的逼真射线追踪信道。该模型考虑了基于超材料的RIS的频率选择性响应，该响应会扩散宽带IR-UWB脉冲，并可能降低通信和感知性能。数值实验量化了RIS频率选择性对UWB ISAC的影响，并表征了ISAC性能与接收机计算能耗之间的权衡。

## Abstract
Neuromorphic computing enables event-driven, low-power inference and is therefore an attractive technology for jointly carrying out communication, sensing, and processing at resource-constrained wireless devices. Impulse radio ultra-wideband (IR-UWB) signaling, which is standardized in the IEEE 802.15.4 family and widely deployed for ranging and short-range communication, is naturally matched to neuromorphic processing, since both operate through sparse temporal events, or spikes. In this context, this paper studies a standard-compliant neuromorphic integrated sensing and communications (N-ISAC) system in which a single spiking neural network (SNN) receiver jointly demodulates digital data and detects a passive radar target directly from a common IEEE 802.15.4z high-rate-pulse-repetition-frequency (HRP) UWB waveform. Unlike prior N-ISAC work, which assumed a basic pulse-position-modulation interface and a simplified multipath channel, we consider the full standardized physical layer together with a realistic ray-traced channel aided by a reconfigurable intelligent surface (RIS). The model accounts for the frequency-selective response of a metamaterial-based RIS, which disperses the wideband IR-UWB pulses and can degrade both communication and sensing. Numerical experiments quantify the impact of RIS frequency selectivity on UWB ISAC and characterize the trade-off between ISAC performance and receiver computation energy.

## 二、方法论：核心思想、关键技术细节

### 1. 系统整体框架
- 系统组成：单天线 UWB 发送端（Tx）、单天线接收端（Rx）、无源目标、超材料 RIS。同一 IR-UWB 波形同时承载通信数据和雷达目标检测，接收端用一个 SNN 联合完成两项任务。
- 与先前工作 [5] 的关键差异：采用完整 IEEE 802.15.4z HRP UWB 物理层（替换基本 PPM），并采用含 RIS 的射线追踪信道。

### 2. UWB 发送端（标准合规物理层）
- **帧结构**：SHR（同步头）+ PHY 载荷，其中 SHR 由 SYNC 和 SFD 字段组成；
- **同步 SYNC 字段**：由标准三元前导码 `a`（长度 Cp）经长度 δp 扩展而成，已知波形用于同步和信道自适应；
- **载荷 BPM-BPSK**：信息比特经 RS 编码 + 卷积编码（0.5 速率）或直通（1.0 速率）后，映射为 BPM 比特（选择突发区间）和 BPSK 比特（决定突发极性），并引入突发跳频和芯片符号加扰；
- **脉冲波形**：8 阶 Butterworth 滤波器，3-dB 带宽 B ≈ 500 MHz。

### 3. RIS 辅助的信道模型
- **3GPP TR 38.901 标准分解**：`h_v(t) = h_bg(t) + v·h_tar(t)`，其中 `v∈{0,1}` 表示目标是否存在；
- **背景分量**：混合模型 = 静态分量（确定性路径）+ 动态杂波（随机子射线）+ RIS 辅助分量（逐单元射线）；
- **目标分量**：包含直接入射类和 RIS 入射类两类目标交互路径，RCS 分解为均值、方向项和残差波动项；
- **RIS 频率选择性**：采用 Lorentzian 谐振模型 `Ψ(ω)`，品质因数 Q = 2πf_c/κ 控制谐振带宽——Q 小则频响平坦，Q 大则谐振窄带、色散强。

### 4. 接收信号处理与相干前端（基线参考）
- 接收信号：发送波形与信道卷积加 AWGN，按芯片速率采样；
- 相干前端：利用已知 SYNC 序列做相关（`c_s = P_s^H y_s`），用 LS 或统计 LMMSE 估计信道，再执行 MMSE 均衡，得到均衡后载荷供后续处理。

### 5. 神经形态接收机（核心贡献）
- **SNN 骨干**：采用离散时间 LIF（SRM 实现），膜电位更新式为
  `u_{k,m} = η_u·u_{k,m-1} + Σ w_{k,j}·ν_{j,m} + b_k - ϑ·ν_{k,m-1}`，
  超阈值发放 `ν_{k,m} = Θ(u_{k,m} - ϑ)`；
- **芯片域稀疏输入编码**：对 SYNC 和每个载荷符号分别做幅度比控制稀疏化（保留比例 ρ），抑制噪声和弱多径，保留脉冲定时关键信息；
- **超网络信道自适应**：将稀疏 SYNC 观测（实虚部拼接）输入超网络，生成逐神经元尺度系数 `w_R`，对该帧 SNN 的每层权重做缩放（`W_R^ℓ = W̃_R^ℓ·diag(w_R^ℓ)`），实现帧级信道自适应而不需要显式信道估计、求逆或均衡；
- **联合 ISAC 推理**：
  - 通信输出：BPM 和 BPSK 读出的膜电位直接作为 LLR，送入标准 FEC 解码器（软输入卷积 + RS 解码或直通）；
  - 感知输出：逐符号目标存在概率经 sigmoid 得到，取帧平均后与 1/2 阈值比较给出目标判决策略；
- **能量感知训练目标**：
  - 联合损失 `L_ISAC = χ·L_c + (1-χ)·L_s`（双交叉熵）；
  - 引入膜电位稀疏正则化（阈值归一化正膜电位的集中度度量）控制尖峰活动；
  - 总目标：`Σ E[L_ISAC + λ_r·Σ R_{ℓ,m}]`，采用代理梯度（sigmoid 导数）解决 Heaviside 不可导问题。

## 六、主要结论与发现

1. **HNet SNN 联合性能最优**：在 RIS 辅助场景下，BLER 在 γc = -5 dB 时约 10⁻²，高 SNR 下目标检测错误低于 0.1；而 LS/LMMSE SNN 虽然高 SNR 下 BLER 更优，但目标检测接近随机猜测（~0.5），说明均衡后的载荷表示不利于感知任务。
2. **RIS 引入通信-感知权衡**：Rx 聚焦的 RIS 显著提升通信可靠性（26.5 dB 路径增益），但在相同接收 SNR 下增加了目标检测错误——增强后的目标无关背景掩盖了目标相关变化。
3. **RIS 频率选择性的非对称影响**：低 Q（宽频响）利于通信；高 Q 抑制目标无关 RIS 背景分量，反而改善目标检测；同时高 Q 降低宽 SNN 的放电率（约 0.24→0.19），窄 SNN 无此趋势，体现容量依赖的事件驱动行为。
4. **标准载荷参数的作用**：低速率（长符号）模式抗多径干扰更好（BLER 更低），但感知优势略逊；27.24 Mb/s 模式（绕过卷积编码）性能全面退化。
5. **计算能量大幅降低**：HNet 接收机能量低于 91 μJ/帧，而 LS/LMMSE 基线超过 4.2 mJ/帧（约 50 倍差距）；输入稀疏化（ρ：1→0.5）使 HNet SNN 能量从约 89 μJ 降至 51 μJ，且 BLER 保持在 5×10⁻³ 附近；HNet ANN 的能量几乎不随 ρ 变化，印证事件驱动优势。
6. **λr 与 ρ 互补**：λr 从 0 增至 10⁻³ 使放电率从约 0.21 降至约 0.05（相对降低 74%），对性能和能量的影响比输入稀疏化更温和，两者构成输入/内部双重稀疏控制机制。

## 七、优点与亮点

- **标准合规性**：首次将 N-ISAC 建立在 IEEE 802.15.4z 完整物理层上（SHR 结构、BPM-BPSK、FEC 链、突发跳频等），研究结论具备工程落地参考价值；
- **物理信道建模的严谨性**：采用 Sionna RT 射线追踪 + 3GPP TR 38.901 兼容的 ISAC 信道分解 + Lorentzian RIS 频选响应，电磁一致性好；
- **新颖的前导码驱动超网络自适应**：直接复用标准 SYNC 字段做帧级任务导向自适应，无需额外导频、显式信道估计或均衡，实现“感知-计算一体”；
- **能量感知的端到端训练**：将尖峰活动稀疏性纳入训练目标，从算法层面实现可调的性能-能耗权衡；
- **纵深实验设计**：同时覆盖标准参数（PRF、码率）、物理环境参数（Q 值、RIS 有无）、算法超参数（ρ、λr）和硬件架构（SNN/ANN）四个层面的分析，结论系统性较强。

## 八、不足与局限

- **算力信息缺失**：未披露 GPU/TPU 型号、数量和训练时长，降低了可复现性和训练成本评估能力；
- **场景单一**：仅一个城市射线追踪场景、一个 RIS 位置/朝向、单天线配置，通用性有待更多场景验证；
- **同步误差简化**：假设 SHR 定时和载荷边界已知，未建模实际同步/检测错误对超网络输入和 SNN 处理的影响；
- **能量模型覆盖有限**

- **能量模型覆盖有限**：接收机能量仅统计了 SNN 推理阶段 MAC/AC 操作，未计入 RF 前端、模数转换、帧检测与同步、FEC 解码、超网络计算以及 RIS 控制链路所消耗的能量；对“事件驱动能效优势”的量化偏乐观，绝对能效指标不宜直接与整机功耗对比；
- **对比基线不够全面**：实验对照集中于信道估计类接收机（LS/LMMSE），未与现代主流神经接收机（如 CNN/Transformer 架构）或经典 UWB 相干接收机（如匹配滤波 + 联合判决）做横向比较，难以判断 HNet SNN 的性能在同代深度学习接收机谱系中的相对位置；
- **感知任务建模简化**：仅处理“目标存在/不存在”二分类和单目标场景，未涉及距离/角度估计、多目标分辨、目标速度等更实际的 ISAC 任务；目标 RCS 残差波动分量建模较为简单，与实测目标特性仍有差距；
- **鲁棒性与泛化未被验证**：超网络只在单一城市射线追踪场景、单一 RIS 位置和单一天线配置下训练与测试，未评估对未见过的环境布局、RIS 朝向、目标位置或信道域偏移的泛化能力，部署到新场景时帧级自适应的有效性存疑；
- **同步与定时误差的理想化假设**：假设 SHR 定时和载荷边界已知，而实际 UWB 接收机需先通过 SYNC 相关峰搜索完成帧检测与同步；超网络输入对 SYNC 观测的定时误差、采样偏移和检测失败极其敏感，该误差传播链路未被建模；
- **RIS 动态重构细节缺失**：Lorentzian 频选模型刻画了静态谐振响应，但未考虑超材料 RIS 相移配置切换时的时间常数、切换损耗、离散相位比特粒度及其对连续脉冲串的影响；RIS 的实时控制开销与通信/感知任务的联合调度也未讨论。

## 九、总体评价与展望

本文是神经形态 ISAC 从理想化模型走向工程化系统的重要一步：以 IEEE 802.15.4z 标准物理层为信号根基，以射线追踪和 3GPP 兼容 ISAC 信道为传播根基，以 LIF-SNN 超网络接收机为算法核心，在“标准合规、物理可信、事件驱动、能量可控”之间达成了较好的平衡。其最具价值的贡献在于：证明了标准前导码本身可作为任务导向信道自适应的驱动信号，从而绕开显式信道估计与均衡，使通信与感知在稀疏事件域内共享同一套神经计算资源。

但该框架距离实际部署仍需补齐三块拼图：一是多场景、多部署条件下超网络自适应能力的泛化验证；二是与帧检测/定时同步、RIS 控制器的端到端联合建模与优化；三是在专用低功耗神经形态芯片（如 Intel Loihi、SpiNNaker 等）上的实测部署与整机能耗评估。若这些环节能够打通，基于标准 UWB 的神经形态 ISAC 有望在数字钥匙、工厂定位、智能家居与车载互联等大规模商用场景中率先落地。
