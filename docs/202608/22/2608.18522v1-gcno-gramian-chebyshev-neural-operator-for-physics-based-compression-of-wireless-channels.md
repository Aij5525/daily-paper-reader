## 摘要
大型天线阵列使无线系统能够服务更多用户并实现更高的数据速率，但也使得信道反馈变得昂贵：接收设备必须反复向基站报告一个大型复值信道矩阵。大多数神经压缩器将该矩阵视为图像，并将其替换为固定长度的码字，只有匹配的神经解码器才能解释该码字。因此，消息无法适应信道复杂度，改变天线数量通常需要重新训练。我们探讨设备是否可以仅报告每个信道背后的少数主导传播路径。我们提出了Gramian切比雪夫神经算子（GCNO），一种基于物理的可变速率压缩器，它识别依赖于样本的路径方向集合。GCNO利用收发信道结构定位路径，使用一阶泰勒校正来细化落在网格点之间的方向，并通过最小二乘法恢复其复强度。它在没有路径标签的情况下进行训练，基站通过传输的路径元组解析地重建信道，而不是通过学习解码器。在三个射线追踪环境中，与神经反馈基线相比，GCNO在相同负载下实现了更好的重建精度，或在相同精度下实现了更低的负载，并且无需重新训练即可迁移到未见过的天线数量。

## Abstract
Large antenna arrays allow wireless systems to serve more users and achieve higher data rates, but they also make channel feedback expensive: the receiving device must repeatedly report a large complex-valued channel matrix to the base station. Most neural compressors treat this matrix like an image and replace it with a fixed-length code that only a matched neural decoder can interpret. The message therefore does not adapt to channel complexity, and changing the antenna count typically requires retraining. We ask whether a device can instead report only the few dominant propagation paths underlying each channel. We introduce the Gramian Chebyshev Neural Operator (GCNO), a physics-based, variable-rate compressor that identifies a sample-dependent set of path directions. GCNO uses receive-transmit channel structure to locate paths, a first-order Taylor correction to refine directions that fall between grid points, and least squares to recover their complex strengths. It is trained without path labels, and the base station reconstructs the channel analytically from the transmitted path tuples rather than through a learned decoder. Across three ray-traced environments, GCNO achieves better reconstruction accuracy at the same payload - or lower payload at the same accuracy - than neural feedback baselines, and transfers to unseen antenna counts without retraining.

## 1. 核心问题与整体含义（研究动机与背景）

- 大规模 MIMO 系统中，基站配备大规模天线阵列，用户需要将下行信道状态信息（CSI）反馈给基站，才能实现波束成形与高数据率传输。
- 直接反馈完整信道矩阵开销巨大：一个 \(N_r \times N_t\) 的复信道矩阵需要 \(2N_rN_t\) 个实数；例如 32×32 信道需要 2048 个实数，且随天线数增加而快速增长。
- 现有基于深度学习的 CSI 压缩方法（如 CsiNet、TransNet、SwinCFNet 等）通常将信道矩阵视为图像，用固定长度的隐码表示，并由匹配的神经解码器重建。这带来两个核心缺陷：
  - 反馈长度不能随信道复杂度自适应变化，简单信道和复杂信道使用同样大小的码字。
  - 编码器-解码器对特定天线配置联合训练，改变天线数量通常需要重新训练模型。
- 本文的核心问题：**能否只反馈每个信道中最主要的少数传播路径参数，而不是固定长度的隐码？**
- 论文提出 Gramian Chebyshev Neural Operator（GCNO），利用信道物理传播结构，识别样本相关的路径方向，通过路径元组实现可变速率、跨天线配置可迁移的 CSI 压缩。

## 2. 方法论

### 核心思想

- 利用几何信道模型：信道可表示为若干传播路径之和，每条路径由 1 个复增益、1 个接收方向、1 个发射方向描述。保留 K 条路径时，只需 \(4K\) 个实数，远小于 \(2N_rN_t\)。
- 用户设备反馈路径元组（复增益实部/虚部、接收有效角、发射有效角），基站直接用已知阵列响应解析重建信道，无需匹配的神经解码器。
- 反馈长度随 K 自适应变化（变速率）。
- 训练过程不需要路径标签，只依赖信道重建误差与速率正则。

### 关键技术细节

1. **方向网格与证据图（Evidence Map）**
   - 在接收/发射方向空间建立均匀网格，每个网格点对应一个字典原子 \(D_{ij}=a_{N_r}(u_{ri})a_{N_t}(u_{tj})^H\)。
   - 计算信道 H 与每个原子的 Frobenius 内积，得到证据图 C，用于显示哪些方向对当前信道有显著贡献。
   - 离网格路径会跨多个相邻网格单元产生能量扩散，因此不能直接用网格点作为最终反馈。

2. **GCNO（Gramian Chebyshev Neural Operator）主干**
   - 输入为归一化信道 H 和证据图 C，分别经轻量编码器融合为复数特征图。
   - 在每个 GCNO 层中，计算接收侧和发射侧的 Gramian 矩阵：
     \[
     G_r = \sum_c X_c X_c^H,\quad G_t = \sum_c X_c^H X_c
     \]
   - 将 Gramian 归一化并映射到 \([-1,1]\)，构造算子 \(A_r, A_t\)，然后使用低阶（Q=3）Chebyshev 多项式进行双侧滤波：
     \[
     Y_c = \sum_{c'} \sum_{p,q} \Theta_{cc'pq} T_p(A_r) X_{c'} T_q(A_t)
     \]
   - 关键创新点：Gramian 是每个样本根据当前信道的结构实时计算的，因此滤波结构是**信道自适应的**；而 Chebyshev 多项式系数 \(\Theta\) 是学习参数，且只与特征通道和多项式阶数相关，不依赖具体天线索引，因此可天然迁移到不同天线尺寸。

3. **Taylor 离网格修正**
   - 对每个网格点，GCNO 输出一个分数图，以及接收/发射方向的连续偏移量 \(\Delta U_r, \Delta U_t\)。
   - 用一阶 Taylor 展开逼近实际连续方向对应的原子：
     \[
     B_{ij} = D_{ij} + \Delta U_r D^r_{ij} + \Delta U_t D^t_{ij}
     \]
   - 偏移限制在半格内，可有效表示落在网格间的主导路径，避免一个物理路径需要多个网格系数表示的问题。

4. **路径选择与增益恢复**
   - 推理阶段：按分数降序扫描候选方向，若候选与原路径高度重复则跳过，否则暂时加入并通过联合岭回归最小二乘重新拟合所有复增益，只有重建误差显著降低时才保留该路径。路径数 K 随信道复杂度自适应变化。
   - 训练阶段：用可微的软选择替代硬选择，包含最大软候选数、活动值 \(\alpha_k\)、重复惩罚等，使整体流程可端到端训练。
   - 最终增益通过无梯度的精确最小二乘求解，避免让神经网络直接预测易不稳定的复增益。

### 算法流程概述（文字）

输入信道 → 归一化 → 构造证据图 → 双分支编码 → 三层 GCNO+LocalGate → 输出分数图和 Taylor 偏移 → 软/硬路径选择 → 最小二乘恢复增益 → 输出路径元组（\(4K\) 个实数）→ 基站按几何信道模型解析重建。

## 6. 主要结论与发现

- 基于物理路径的变速率压缩优于固定长度神经码：
  - 在相同反馈负载下重建 NMSE 更低，或在相同目标 NMSE 下所需反馈值更少。
- GCNO 的样本自适应 Gramian-Chebyshev 滤波优于通用 CNN/FNO/静态 Chebyshev 替换结构；此增益不仅是解析解码器带来的。
- Taylor 偏移修正是紧凑路径表达的关键：没有该模块时，NMSE 严重恶化，角误差显著增大。
- GCNO 无需重训即可迁移到未见过的天线尺寸（如 32×32 训练迁移到 16×16、16×32、32×64、48×48 等），而固定编码器-解码器基线在非原生尺寸下大幅退化。
- 路径数量随目标精度自适应增加，简单信道保留少量路径，复杂信道保留更多路径，体现了可变速率的意义。
- 传输方向与真实强传播路径具有较高一致性（强路径 F1≈0.832，加权召回≈0.916，中位联合角误差≈0.225°），并能在波束成形任务中接近完美 CSI 的频谱效率。
- 模型仅约 95K 参数，远小于最接近的神经基线，却获得更优的率失真性能。

## 7. 优点

- **问题定义有新意**：从“压缩矩阵”转向“压缩物理路径集合”，直接利用信道稀疏多径结构。
- **变速率反馈**：反馈长度随信道复杂度自适应，兼具理论基础（附录 A 给出最小维度定理）。
- **跨天线迁移**：信道自适应 Gramian 和共享 Chebyshev 系数使模型天然不绑定天线尺寸。
- **无需路径标签训练**：以重建损失和速率正则端到端训练，减轻标注与监督依赖。
- **分析式重建**：基站只使用已知阵列响应合成信道，不依赖匹配解码器，降低部署耦合。
- **模型轻量**：95K 参数，推理吞吐高，适合资源受限的终端设备。
- **实验充分且公平**：覆盖多场景、多基线、多消融以及不利种子协议下的稳健性验证。

## 8. 不足与局限

- **实验范围仍偏窄**：
  - 仅评估窄带空间信道，未纳入宽带、OFDM、多载波场景；
  - 仅使用均匀线性阵列（ULA），未验证均匀平面阵列（UPA）或任意几何；
  - 未考虑多用户调度、信道估计噪声、量化反馈反馈误差累积等实际链路效应。
- **对物理路径模型的依赖**：方法在信道可由少量路径主导时表现最好；若信道具有强弥散分量或路径数较多，自适应停止规则可能丢弃有用能量。
- **不能检测所有路径**：论文自认路径召回对“强路径数”较多的信道会降低，即只保留可分辨的主要结构，而非完整射线轨迹集。
- **训练/推理差异**：训练时用软选择与 Taylor 原子，部署时用硬选择与精确原子；两者之间的差异虽经实验证明可行，但理论一致性并未完全闭环。
- **基线适配依赖插值规则**：跨天线尺寸对比中为神经基线设计了固定确定性插值适配器，这种适配器并非基线原生能力，可能并非最公平的“迁移”对照，只是论文给定协议下的结果。
- **部分附录细节较繁琐**：大量超参数、训练调度和硬件记录虽增强可复现性，但核心算法描述在正文中可更精炼。
