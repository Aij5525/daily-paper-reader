## 摘要
集成感知与通信（ISAC）是下一代无线网络的关键技术，能够在共享频谱和硬件资源上实现通信和雷达感知。然而，在实际的多用户多输入多输出（MU-MIMO）ISAC发射机中，天线单元之间的互耦（MC）会扭曲阵列导向矢量以及每个通信用户（CU）的信道，导致感知波束方向图偏离期望方向图，并使到每个用户的通信链路性能下降。为了解决这一问题，我们提出一种稳健的互耦补偿波束赋形设计，该设计针对残余互耦误差保证了MU-MIMO ISAC发射机的感知和通信性能。我们在互耦矩阵上引入残余误差，使得范数有界残余误差同时引起感知波束方向图的不确定性和通信信道的不确定性。然后针对每种不确定性的最坏情况优化发射协方差，在保证每个CU信干噪比（SINR）的同时，最小化感知的最坏情况波束方向图匹配均方误差（MSE）。将每个最坏情况约束转化为线性矩阵不等式，问题转化为凸半定规划（SDP）。数值结果表明，与常规设计相比，所提出的稳健设计实现了更低的感知波束方向图匹配MSE和更高的通信SINR，并且随着残余误差的增大，这一优势会扩大。

## Abstract
Integrated sensing and communications (ISAC) is a key technology for next-generation wireless networks, enabling communication and radar sensing over shared spectral and hardware resources. In practical multi-user multiple-input multiple-output (MU-MIMO) ISAC transmitters, however, mutual coupling (MC) between antenna elements distorts the array steering vector and each communication user (CU) channel, so that the sensing beampattern deviates from the desired one and the communication link to each user degrades. To address this limitation, we propose a robust MC-compensated beamforming design that guarantees both the sensing and communication performance of MU-MIMO ISAC transmitters against the residual MC error. We introduce a residual error on the MC matrix, so that a norm-bounded residual error induces both the sensing beampattern uncertainty and the communication channel uncertainty. The transmit covariance is then optimized against the worst-case of each uncertainty, minimizing the worst-case beampattern matching mean-squared error (MSE) for sensing while guaranteeing the signal-to-interference-plus-noise ratio (SINR) for each CU. Each worst-case constraint is converted into a linear matrix inequality, and the problem becomes a convex semidefinite program (SDP). Numerical results show that the proposed robust design attains both a lower sensing beampattern matching MSE and a higher communication SINR than those of the conventional designs, with an advantage that widens as the residual error grows.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：集成感知与通信（ISAC）是下一代无线网络的关键技术之一，允许单个收发机在共享频谱与硬件资源上同时实现通信和雷达感知。在多用户多输入多输出（MU-MIMO）ISAC系统中，发射波束赋形需要同时塑造期望的感知波束方向图，并保证每个通信用户（CU）的信干噪比（SINR）需求。
- **核心问题**：在实际ISAC发射机中，天线单元之间存在**互耦效应（Mutual Coupling, MC）**，即各单元辐射的场会耦合进相邻单元，导致：
  - 阵列导向矢量发生畸变，感知波束方向图偏离期望方向图；
  - 每个用户的通信信道受到破坏，波束赋形增益降低，信道状态信息（CSI）失真。
- **现有方法的不足**：
  - 传统**MC补偿设计**仅用固定物理模型替换理想导向矢量，在模型存在残余误差时缺乏鲁棒性；
  - 现有**鲁棒ISAC设计**（如针对CSI误差、目标位置不确定性）将不确定性集合以理想响应为中心，误差界必须同时吸收全部MC偏差和残余偏差，导致设计过度保守。
- **研究意义**：目前尚无研究针对残余MC误差同时保证雷达感知与MU-MIMO通信性能的鲁棒波束赋形设计。本文填补了这一空白。

## 2. 论文提出的方法论

### 2.1 核心思想

- 在基于物理模型的MC矩阵上引入**范数有界残余误差**，使不确定性集合以物理模型（MC补偿后的响应）为中心，而非理想响应为中心，从而显著降低保守性。
- 残余误差**同时**诱导感知导向矢量的不确定性和通信信道的不确定性，将二者统一到同一个最坏情况优化框架中。
- 通过最坏情况优化：最小化感知波束方向图匹配MSE，同时保证每个用户的SINR需求，并将所有最坏情况约束转化为**线性矩阵不等式（LMI）**，最终形成凸**半定规划（SDP）**问题。

### 2.2 系统模型与关键公式

- **信号模型**：发射信号 \( x = W_c c + W_s s \)，其中 \( W_c \) 为通信波束赋形矩阵，\( W_s \) 为感知波形矩阵。
- **互耦模型**：基于物理模型的负载终端MC矩阵：
  \[
  Z = (Z_{\text{self}} + Z_L)(Z_{oc} + Z_L I_{N_t})^{-1}
  \]
  归一化后 \( \bar{Z} = Z/g \)，耦合导向矢量 \( a_{MC}(\theta) = \bar{Z} a(\theta) \)，耦合信道 \( h_{MC,k} = \bar{Z} h_k \)。
- **鲁棒误差模型**：
  \[
  Z_{\text{rob}} = \bar{Z} + \Delta, \quad \|\Delta\|_2 \le \varepsilon
  \]
  由此推导出感知误差界 \( \varepsilon_s = \sqrt{N_t}\varepsilon \) 和每用户信道误差界 \( \varepsilon_{c,k} = \varepsilon\|h_k\|_2 \)。

### 2.3 优化问题与求解

- **原问题 (P0)**：最小化感知波束匹配MSE，受限于各用户SINR约束和每天线功率约束。
- **稳健设计 (P3)**：在最坏情况残余MC误差下最小化感知MSE，并保证每个用户最坏情况SINR：
  \[
  \min_{R,\{R_{c,k}\}} \max_{\|\Delta\|_2\le\varepsilon} f_{r,\text{rob}} \quad \text{s.t.} \quad \gamma_k \ge \Gamma,\ \forall k, \text{(功率约束)}, \text{(协方差约束)}
  \]
- **关键转化步骤**：
  1. 引入辅助变量 \( S_m \) 上界最坏情况匹配误差；
  2. 将波束方向图约束和SINR约束统一写成共同形式：
     \[
     (x+e)^H Q(x+e) \ge \beta,\quad \forall \|e\|_2 \le r
     \]
  3. **Lemma 1（S-procedure）**：上述条件当且仅当存在 \( \lambda \ge 0 \) 使如下LMI成立：
     \[
     L(Q,x,\beta,r,\lambda) =
     \begin{bmatrix}
     Q + \lambda I & Qx \\
     x^H Q & x^H Q x - \beta - \lambda r^2
     \end{bmatrix} \succeq 0
     \]
  4. 将波束方向图两侧约束（21a/21b）和SINR约束（22）分别应用Lemma 1，得到LMI约束（25）、（26）、（27）。
- **最终问题 (P′₃)**：凸SDP，优化变量为协方差矩阵、每用户波束赋形协方差、辅助变量及S-procedure乘子，约束为LMIs加功率/协方差约束。

### 2.4 计算复杂度

- 相比非鲁棒设计 (P1)/(P2)，鲁棒设计 (P′₃) 仅增加 \( 3M+K \) 个标量变量，但增加了 \( 2M+K \) 个大小为 \( N_t+1 \) 的LMI块。
- 复杂度为 \( O(\sqrt{M}N_t) \) 量级迭代次数，整体仍为多项式复杂度，仅比非鲁棒设计多因子 \( \sqrt{M/(K+1)} \)，这是施加逐角度逐用户最坏情况保障的代价。

## 6. 主要结论与发现

1. **鲁棒MC补偿设计在感知和通信性能上均优于传统设计**：
   - 在相同实现SINR下，鲁棒设计取得更低的波束匹配MSE；

2. **优势随残余MC误差增大而扩大**：在 \( \tilde{\eta} = -6 \) dB 时，鲁棒设计相比MC补偿设计的MSE优势比 \( \tilde{\eta} = -12 \) dB 时更明显。

4. **在接近设计误差界时**，鲁棒设计与普通MC补偿设计表现接近；但当实际失配超过设计界时，鲁棒设计显著胜出。
5. **用户数影响**：在中等SINR目标以下，MSE不受用户数影响；SINR目标较高时，用户数越多，MSE上升越早。

## 7. 优点

- **不确定性建模创新**：将残余误差直接放在物理MC矩阵上，使不确定性集合以MC补偿模型为中心，而非理想响应为中心，有效避免了过度保守，这是与现有鲁棒ISAC设计的本质区别。
- **统一问题框架**：将感知波束方向图约束和通信SINR约束统一为共同的二次型形式（\( (x+e)^H Q(x+e) \ge \beta \)），通过S-procedure统一转化为LMI，方法简洁、理论完备。
- **凸优化保证**：最终问题为凸SDP，可高效求解，且复杂度保持在多项式量级，实用性较强。
- **最坏情况保障明确**：通过尾部百分位指标（95th MSE、5th SINR）评价，符合鲁棒优化面向最坏情况的设计意图。
- **同时覆盖感知和通信**：同一残余MC误差同时扰动感知导向矢量和通信信道，建模一致性高，联动效果被充分考虑。
