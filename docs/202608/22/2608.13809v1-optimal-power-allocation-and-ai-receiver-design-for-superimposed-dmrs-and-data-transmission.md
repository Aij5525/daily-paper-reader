## 摘要
本文研究了基于正交频分复用（OFDM）的多输入多输出（MIMO）系统中叠加（SI）解调参考信号（DMRS）与数据的传输。首先，我们推导了一个分析框架，用于描述迭代信道估计（CE）与MIMO检测（MD）过程中，信道估计和检测的均方误差（MSE）之间的迭代行为。该框架随后被用于优化SI-DMRS传输中DMRS与数据符号之间的功率分配和导频图案。其次，我们设计了一种基于Transformer编码器的人工智能（AI）接收机，用于SI-DMRS传输，该接收机结合了迭代CE与检测（ICED）结构。仿真结果表明，所提出的AI-ICED接收机结合SI-DMRS，相较于使用非重叠DMRS和数据符号的传统系统，有效提高了频谱效率（SE）。

## Abstract
In this paper, we consider transmissions with superimposed (SI) demodulation-reference-symbol (DMRS) and data in orthogonal frequency-division multiplexing (OFDM) based multiple-input multiple-output (MIMO) systems. First, we derive an analytical framework to characterize the iterative behavior between the mean-square errors (MSEs) of channel estimation (CE) and MIMO detection (MD) within an iterative CE and detection (ICED) process. This framework is subsequently utilized to optimize power allocation and pilot patterns between the DMRS and data symbols for SI-DMRS transmission. Second, we design an artificial intelligence (AI) based receiver built upon Transformer encoders for SI-DMRS transmissions, which incorporates an iterative CE and detection (ICED) structure. Simulation results demonstrate that the proposed AI-ICED receiver, combined with SI-DMRS, effectively increases spectral efficiency (SE) compared to conventional systems using non-overlapped DMRS and data symbols.

- 为提升 SE，业界提出了**叠加 DMRS（SI-DMRS）** 方案，即将 DMRS 直接叠加在数据符号上传输。这样做虽然实现了**零导频开销**，却引入了新的核心矛盾：
  - 叠加后的信号中，CE（信道估计）与 MD（MIMO 检测）**互相纠缠**，难以用传统模块化方法获得满意的性能；
  - 总发射功率需要在 DMRS 和数据之间**分摊**，导致 CE 精度下降，进而影响数据检测。

- 与此同时，基于 Transformer 的大模型与上下文学习（ICL）范式为设计统一、高性能的 AI 接收机提供了新灵感——将少量导频及其位置视为“上下文提示”，直接映射观测到符号空间。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想
- **理论层面**：建立 ICED 过程中 CE-MSE 与 MD-MSE 的迭代演化解析框架，利用**平衡态**分析直接求解收敛后的 MSE，从而避免耗时的数值仿真。
- **工程层面**：设计一种基于 Transformer 编码器的 AI-ICED 接收机，将 CE 与 MD 统一为联合上下文学习问题，通过**物理引导特征构造（PGFC）** 在迭代之间传递结构化物理特征。

### 2.2 理论分析框架

#### 系统模型设定
- MIMO-OFDM 系统，Nt 根发射天线，Nr 根接收天线。
- 一个子帧内：N 个 RE 仅承载数据（功率因子 a），M 个 RE 同时承载 SI-DMRS 和数据（DMRS 功率因子 b，数据功率因子 (1−b)k），其中 k=1+μ(1−a)，μ=N/M，总功率归一化为 N+M。

#### 关键公式（文字描述）
- **CE-MSE 迭代更新（单 RE）**：推导得出 CE-MSE 的更新式，其中包含前一迭代的 CE-MSE p 与 MD-MSE q、噪声方差 σ²、功率因子 b 和 k 的联合表达式。
- **CE 去噪**：在 DMRS 导频间应用 LMMSE 滤波器，相干处理增益最大为 M/Nt，引入因子 γ≥1 表征实际增益损耗，得到去噪后的 CE-MSE p 的表达式。
- **MD-MSE 更新**：近似推导 MD-MSE q 的表达式，由噪声、残余 DMRS 干扰及 CE 误差共同决定。
- **平衡态（Property 1）**：由 p、q 两式构成平衡方程组，可化简为关于 p 的三次多项式方程：
  - Ap³ + Bp² + Cp + D = 0，其中 A、B、C、D 为 u=1−b、v=σ²/k、ρ=γNt/M 的组合系数。
  - 该性质证明了 ICED 过程中存在稳定平衡态，使最优功率分配可解析求解。

#### MIESM 组合两子集性能
- 将两类 RE（含/不含 SI-DMRS）的 MD-MSE 分别转换为等效 SNR：θ₁=1/q−1，θ₂=1/t−1。
- 通过星座约束互信息函数 fMI(·) 映射为 MI，按 RE 数量加权平均后反变换回等效 SNR θeff，用于评估最终解码性能。
- t（无 DMRS 数据 RE 上的 MD-MSE）表达式：t=(ap+σ²)/(a(1+p)+σ²)。

#### 最优功率分配结论
- 功率因子 b 存在最优值：过低则导频功率不足、CE 差；过高则数据功率不足、MD 差。最优 b 随 SNR 升高而增大。
- 联合优化 (a,b) 可进一步获益：在示例中，将 a 从 1 降至 0.67 使有效 MD-MSE 从 −10.42 dB 降至 −12.2 dB。
- 叠加更多 DMRS 并非总是有利：去噪增益 γ/M 恒定时，M=24 配置优于 M=48/96 配置（约 1.55 dB 增益），说明存在最优导频数量权衡。

### 2.3 AI-ICED 接收机设计

#### 整体架构
处理三个输入张量：接收信号 Y、DMRS 符号 sp、DMRS 坐标掩码 Ωp。结构为级联循环：**Tokenizer → ICED 模块 → PGFC 模块 → 下一级迭代**。

#### Tokenization（分词器）
- 将物理张量按 RE 坐标展平，拼接接收信号、重建符号、导频掩码构成原始特征向量。
- 通过线性映射投影到 dvirtual 维潜在空间，形成长度 L=Nsym·Nsc 的 token 序列。

#### ICED Backbone
- 采用包含最新 VWN（虚拟宽度网络）、TPA（张量积注意力）、MoE（混合专家）的 Transformer 编码器块。
- CE 路径：若干 VWN-TPA-MoE 编码器块处理 token 序列 → 线性投影头重建信道张量 Ĥ。
- MD 路径：通过**加法残差融合桥**组合原始 token、高维信道隐特征、重建信道投影，再经 NMD 个编码器块后由分类头输出 PAM 符号 logits。

#### PGFC（物理引导特征构造）
- 在迭代之间构造通信理论张量：干扰消除结果 R=Y−Ĥ·S̃、匹配滤波输出 Z_MF=(Ĥ)†Y、Gram 矩阵 G=(Ĥ)†Ĥ 等，作为下一阶段输入特征。
- 作用：减少网络从数据中学习基础空间投影的负担，加速收敛并提高跨信道泛化能力。

#### 训练损失
- 每阶段损失为 CE-MSE 与检测交叉熵的加权和（权重 β1）。
- 采用**深度监督**：所有中间阶段损失按权重 β2 注入总损失，缓解梯度消失。

## 6. 论文的主要结论与发现

1. **平衡态存在性**：ICED 过程中 CE-MSE 和 MD-MSE 存在稳定平衡态，可通过求解三次方程直接获得，无需仿真迭代。
2. **最优功率分配**：DMRS 功率因子 b 存在最优值（示例中约 0.8），且最优 b 随 SNR 升高而增大；联合优化数据功率因子 a 可带来约 1.8 dB 额外增益。
3. **并非叠加越多越好**：是否增加 SI-DMRS 数量取决于去噪增益与系统参数，存在最优平衡点。
4. **快速收敛**：AI-ICED 接收机在 2–3 次迭代内 CE-MSE 和 BLER 均快速收敛，追加迭代带来约 0.5 dB SNR 增益。
5. **接近最优检测性能**：在 genie-CSI 条件下，AI-ICED 接收机的检测性能逼近最优 MLD。
6. **频谱效率提升**：相比 5G-NR 非重叠 DMRS 基线，SI-DMRS + AI-ICED 方案在全部 SNR 区间内吞吐量均更高，消除了导频开销带来的吞吐量饱和上限（最高 20% SE 增益）。

## 7. 优点：方法或实验设计上的亮点

1. **理论分析与 AI 设计深度结合**：先建立完善的解析框架指导功率分配，再针对残余问题设计 AI 接收机，避免纯黑盒方法，可解释性较强。
2. **MIESM 映射合理实用**：将两类 RE 的 MD-MSE 通过互信息映射组合成等效 SNR，使理论分析与实际解码性能对齐，工程实用性高。
3. **Transformer 架构技术前沿**：集成 VWN、TPA、MoE 等最新架构设计——TPA 低秩张量分解降低投影复杂度、VWN 解耦记忆容量与计算宽度、MoE 保持参数容量同时控制活跃计算。
4. **PGFC 机制设计巧妙**：在迭代之间注入显式物理特征（IC 结果、MF 输出、Gram 矩阵），融合物理模型的归纳偏置与深度学习的表征能力，加速收敛并改善泛化。

6. **复杂度分析透明**：论文提供 per-stage 计算复杂度对比表，明确 VWN/TPA/MoE 各自对复杂度的影响。
