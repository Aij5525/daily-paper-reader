## 摘要
在深度神经网络（DNN）设计中利用无线策略的数学性质可以提高学习性能和泛化能力，同时降低训练复杂度。置换等变性和置换不变性已被纳入DNN架构中。本文研究共轭等变性（CE），并提出一个通用的共轭等变神经网络（CENN）框架用于预编码学习。我们首先证明一类统一的预编码问题的最优策略满足CE，即当信道矩阵共轭时，最优预编码器的共轭仍然是最优的。然后我们表明，对于具有线性处理函数的DNN，强制CE会限制其学习最优预编码策略的能力。为了克服这一限制，我们开发了一种通用的非线性构造，并证明它可以将任意基函数转换为CE处理函数，同时保留基函数原有的等变性质。这种构造使现有的等变网络能够在不增加可学习参数的情况下纳入CE。针对全数字和RIS辅助预编码的仿真表明，所得到的CE增强网络提高了学习和泛化性能，同时比原始网络需要更少的训练样本和更短的训练时间。

## Abstract
Exploiting mathematical properties of wireless policies in deep neural network (DNN) design can improve learning performance and generalizability while reducing training complexity. Permutation equivariance and permutation invariance have been incorporated into DNN architectures. In this paper, we investigate conjugation equivariance (CE) and propose a general conjugation-equivariant neural network (CENN) framework for precoder learning. We first establish that the optimal policies for a unified class of precoding problems satisfy CE, i.e., when the channel matrices are conjugated, the conjugate of an optimal precoder remains optimal. We then show that, for DNNs with linear processing functions, enforcing CE restricts their ability to learn optimal precoding policies. To overcome this limitation, we develop a general nonlinear construction and prove that it converts an arbitrary base function into a CE processing function while preserving the base function's original equivariance properties. This construction enables existing equivariant networks to incorporate CE without adding learnable parameters. Simulations for fully digital and RIS-aided precoding show that the resulting CE-enhanced networks improve learning and generalization performance while requiring fewer training samples and shorter training time than their original counterparts.

## 一、论文的核心问题与整体含义（研究动机和背景）

- 预编码优化是提升无线通信系统频谱效率的关键技术，但传统数值优化方法（如 WMMSE、BCD）需要迭代计算，在线计算开销大。
- 深度神经网络（DNN）在离线训练后可实现低复杂度在线推理，但传统 DNN 常面临训练复杂度高（参数多、样本需求大、训练时间长）和泛化能力有限的问题。
- 将无线策略的数学性质作为归纳偏置（inductive bias）引入 DNN 结构，可以有效提升学习性能、泛化能力并降低训练复杂度。已有工作利用了置换等变性（PE）、置换不变性（PI）、酉等变性（UE）和环面等变性（TE）等性质。
- 本文指出了一个被忽视的重要性质——共轭等变性（Conjugation Equivariance, CE），即信道矩阵共轭后，最优预编码器的共轭仍然是最优的。目前尚未有工作将 CE 与 PE、UE、TE 联合利用于预编码学习。
- 核心问题有两层：(1) 证明一类预编码问题的最优策略确实满足 CE；(2) 在线性处理函数的 DNN 中强制 CE 会限制模型表达能力，因此需要设计通用的非线性构造，使现有等变网络在不增加可学习参数的前提下纳入 CE。

## 二、论文提出的方法论

- **命题 1（CE 性质成立性）**：通过反证法证明，若 \hat{W} 是信道 H 下的最优预编码，则 \hat{W}* 是信道 H* 下的最优预编码。该结论奠定了 CE 网络的合理性基础。
- **线性处理函数的局限性**：若神经网络的层处理函数为线性形式 \psi(d) = Wd + b，要满足 CE 则必须 W 和 b 均为实值。这导致输出实部仅由输入实部决定、虚部仅由输入虚部决定（式 10），无法捕捉预编码解中实部与虚部的相互耦合（例如 (H^H H + νI)^-1 H 的结构），从而严重限制学习能力。
- **非线性构造（命题 2）**：一个函数 \psi 满足 CE（\psi(d*) = \psi(d)*）当且仅当存在任意基函数 \phi 使得：
  \[
  \psi(d) = \frac{1}{2}[\phi(d) + \phi(d*)*]
  \]
  该构造使任意非线性处理函数（如现有等变网络中的处理函数）都能被转化为 CE 处理函数。
- **保留原有等变性质（命题 3）**：若基函数 \phi 满足某种等变性（如 PE、UE、TE），且 \Pi* 也是同类型合法变换矩阵，则通过上述构造得到的 \psi 同时满足 CE 和原有等变性，即 \psi(\Pi d*) = \Pi \psi(d)*。
- **激活函数设计**：采用 \sigma(x) = x / (1 + |x|)，该激活函数满足共轭等变性，且与 PE、UE、TE 兼容。
- **网络整体设计**：将上述 CE 处理函数与 CE 激活函数相结合，构成 CENN 层更新（式 4），从而将任意现有等变网络转换为 CE 增强网络，且不增加任何可学习参数。
