## 摘要
我们提出了一种面向无线边缘-云推理的任务感知语义分割学习（SL）框架，其中传输的潜在表示可靠性根据其对于下游任务的相关性进行动态调整。基于自编码器（AE）的物理（PHY）层实现了通信接口的端到端学习，同时通过训练期间基于互信息（MI）驱动的潜在分量优先级排序来实现不等差错保护（UEP）。估计的MI相对于每个潜在分量的梯度作为任务相关性的基于敏感度的代理，提供了一种完全由学习驱动的优先级排序，该排序同时适应数据分布和下游任务。我们进一步表明，这种优先级排序转化为可测量的物理层效应：与等差错保护（EEP）基线相比，MI引导的UEP为最关键的任务潜在分量分配了显著更高的发射功率。在真实世界物联网传感数据上的实验表明，在不同信噪比（SNR）范围内，该框架相对于等保护和固定UEP基线均有一致的性能提升。额外分析证实了排序稳定性、估计器鲁棒性以及跨数据集和任务类型的泛化能力，表明所提出框架具有广泛的适用性。

## Abstract
We propose a task-aware semantic split learning (SL) framework for wireless edge-cloud inference, in which the reliability of transmitted latent representations is dynamically adapted to their relevance for the downstream task. An autoencoder (AE)-based physical (PHY) layer enables end-to-end learning of the communication interface, while unequal error protection (UEP) is realized via mutual information (MI)-driven prioritization of latent components during training. The gradient of the estimated MI with respect to each latent component serves as a sensitivity-based proxy for task relevance, providing a fully learning-driven prioritization that adapts to both the data distribution and the downstream task. We further show that this prioritization translates into measurable physical-layer effects: MI-guided UEP assigns significantly higher transmit power to the most task-critical latent components compared to the equal error protection (EEP) baseline. Experiments on real-world IoT sensing data demonstrate consistent gains over equal and fixed-UEP baselines across SNR regimes. Additional analysis confirms ranking stability, estimator robustness and generalization across datasets and task types, indicating broad applicability of the proposed framework.

- 在物理（PHY）层，基于自编码器（AE）的设计可端到端训练无线收发机，天然支持不等差错保护（UEP），允许对不同信息部分分配不同可靠性级别。
- 现有语义UEP研究大多基于预定义保护等级或重构驱动的标准，**未从分割学习接口处个体潜在分量的任务相关性出发推导UEP**。

**核心问题：**
在无线边缘-云推理的语义分割学习框架中，如何动态确定哪些潜在表示分量对下游任务最关键，并据此在物理层进行差异化的可靠性分配（即自适应UEP），从而提升任务级性能？

## 2. 论文提出的方法论

**核心思想：**
将分割学习接口处的不等差错保护重新定义为**任务驱动的信息分配问题**——保护级别由每个潜在分量对预测任务的贡献动态决定，该贡献通过潜变量 Z 与目标变量 T 之间的互信息（MI）量化，利用 MI 梯度的绝对值作为任务相关性的局部敏感性代理。

**关键技术细节与流程：**

1. **系统架构（SL + 语义通信 + AE物理层）：**
   - 边缘设备由语义编码器 fsem（两层LSTM中的第一层）和信道编码器 fch（单隐层FC + 批归一化）组成，即 fE = fch ∘ fsem。
   - 服务器端由信道解码器 gch 和语义解码器 gsem（第二个LSTM层 + FC层）组成，即 fS = gsem ∘ gch。
   - 信道建模为瑞利块衰落信道：S̃ = h⊙S + η，无需显式CSI估计，gch 通过端到端训练隐式学习信道统计的逆映射。

2. **学习驱动的UEP机制：**
   - 利用**Donsker–Varadhan (DV) 下界**通过神经判别器 fθ(Z, T) 估计互信息 I(Z;T)。
   - 每批次计算 MI 估计相对于 Z 的梯度，将梯度幅值最大的 L 个潜在分量标记为任务关键分量 Kimp。
   - 信息论依据：∂I(Z;T)/∂z_k = −∂H(T|Z)/∂z_k，因此|∂Î/∂z_k|可作为 IB 原理中充分统计准则的局部微分替代指标。
   - UEP通过加权重构损失实现：LUEP = λ∑_{k∈Kimp}‖ẑ_k−z_k‖² + (1−λ)∑_{k∉Kimp}‖ẑ_k−z_k‖²，其中 λ∈(0.5, 1)。
   - 关键分量识别和信道编解码器更新在**单个统一的反向传播过程**中完成，无单独或人工配置阶段。
   - 总损失：L_total = L_task + L_UEP + L_MI（其中 L_task 为预测MSE，L_MI 为负DV界）。

3. **功率分配效果：** 虽然无显式功率分配层，但通过加权损失，优化器将选中的潜在分量映射到具有更高有效信号能量的信道配置中，从而实现物理层可靠性的差异化。

## 6. 论文的主要结论与发现

1. **语义预处理普遍有益**：LSTM编码器输出的语义表示在EEP和UEP下均优于传输原始输入，且维度降低时仍有竞争力。
2. **MI引导UEP显著优于EEP和固定UEP**：在全部SNR范围内，任务MSE持续更低，且L=5、λ=0.7为最优配置。
3. **过度保护适得其反**：λ=0.9时性能退化向EEP靠拢，表明过度集中保护于小子集是次优的。
4. **学习到的优先级排序可转化为真实物理层效应**：Top-5分量获得比EEP基线高21%的发射符号能量，而Bottom-5低16%——说明UEP不只是损失层面的影响，而是实现了实际的资源再分配。
5. **重构MSE与任务MSE分解离**：重构精度不代表任务性能，验证了面向任务的保护逻辑的必要性。
6. **方法稳定且通用**：DV估计器在各类批次大小下收敛稳定、Top-5排名一致性超过88%、排序不受估计器类型影响；在Amazon数据集和UCI HAR分类任务上均一致优于基线。

## 7. 优点
