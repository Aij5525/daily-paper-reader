## 摘要
Token通信在Transformer Token的粒度上实现了语义通信原理，为资源受限边缘系统中的客户端-服务器协同推理提供了有前景的方向。然而，直接传输Token嵌入带来了两个实际挑战：巨大的通信开销和跨模型特定Token嵌入空间的互操作性有限。为了解决这些挑战，我们提出了一种面向Token的语义通信框架。在该框架中，Token级任务相关性决定了要传输哪些压缩图像潜变量，从而在不直接传输Token嵌入的情况下实现Token粒度的传输。该框架是模块化的，协调三个预训练组件——轻量级客户端视觉Transformer（ViT）、学习型图像压缩（LIC）模型和大型服务器端ViT——而无需端到端训练。关键使能因素是ViT补丁Token与LIC潜向量之间的一一空间对齐，这允许Token级任务相关性直接决定传输哪些潜向量。基于这种对齐，Token对齐的LIC选择性地传输任务相关的潜变量；层选择性注意力展开在单次前向传播中从选定的注意力层范围估计Token相关性；代理Token替换通过优化单个可学习Token来适应冻结的服务器模型。在ImageNet上的实验表明，与近期的语义通信方案、手工设计的编解码器和任务无关的LIC模型相比，所提出的框架实现了更有利的率-精度权衡。

## Abstract
Token communications realize the semantic communication principle at the granularity of transformer tokens, providing a promising direction for client--server collaborative inference in resource-constrained edge systems. However, directly transmitting token embeddings presents two practical challenges: substantial communication cost and limited interoperability across model-specific token embedding spaces. To address these challenges, we propose a \emph{token-oriented} semantic communication framework. In this framework, token-level task relevance determines which compressed image latents are transmitted, enabling token-granular transmission without directly transmitting token embeddings. The framework is modular, coordinating three pretrained components---a lightweight client-side vision transformer (ViT), a learned image compression (LIC) model, and a large server-side ViT---without end-to-end training. The key enabler is the one-to-one spatial alignment between ViT patch tokens and the LIC latent vectors, which allows token-level task relevance to directly determine which latent vectors are transmitted. Building on this alignment, token-aligned LIC selectively transmits task-relevant latents, layer-selective attention rollout estimates token relevance from a selected range of attention layers in a single forward pass, and surrogate token substitution adapts the frozen server model by optimizing a single learnable token. Experiments on ImageNet show that the proposed framework achieves a more favorable rate--accuracy trade-off than recent semantic communication schemes, hand-crafted codecs, and task-agnostic LIC models.

### 1. 核心问题与整体含义

**研究背景**：随着Transformer架构在AI领域的广泛应用，Token已成为统一的计算单元。在AI原生无线网络背景下，语义通信逐渐从传统的比特级通信向面向任务目标的通信范式转变。Token通信作为这一理念的载体，有望在资源受限的边缘系统中实现高效的客户端-服务器协同推理。

**核心问题**：直接传输Token嵌入面临两个关键挑战：
- **通信成本高**：每个Token是高维嵌入向量，即便只传输少量Token也会产生庞大数据量。
- **跨模型互操作性差**：独立训练模型的Token嵌入空间差异显著，因架构、预训练过程和优化目标不同而无法通用交换。

**解决方案**：本文提出一种**面向Token（token-oriented）的语义通信框架**，通过将Token级任务相关性集成到图像压缩过程中，实现**不直接传输Token嵌入**的Token粒度通信。框架协调三个预训练组件（轻量客户端ViT、LIC模型、大型服务器端ViT），无需端到端联合训练，保持完全模块化。

**关键使能**：ViT的patch token（patch size=16）与LIC潜变量（4个stride-2卷积层）在空间上具有**一一对应关系**（即N=H×W/16²），使得Token级任务相关性可直接决定哪些潜变量被传输。

### 2. 方法论

#### 2.1 总体框架

框架遵循"客户端估计相关性 → 选择性压缩传输 → 服务器重建与适配推理"的流程：

1. 客户端使用轻量ViT（DeiT-Tiny）提取视觉Token并估计Token级任务相关性。
2. 根据相关性得分，通过阈值δ构造Token选择图 **s**。
3. 客户端使用LIC模型生成只包含选择位置潜变量的压缩比特流。
4. 服务器接收后重建图像，用代理Token（surrogate token）替换未选择位置的Token。
5. 大型服务器ViT（DeiT-III-Large）完成最终分类。

#### 2.2 三个核心技术组件

**（1）Token对齐的LIC（Token-Aligned LIC）**：

- 利用ViT patch与LIC潜变量的空间一一对应关系，将Token选择图直接作为潜变量的掩码。
- 基于均值-尺度超先验熵模型，潜变量元素在给定超先验条件下条件独立，因此可独立熵编码和解码。
- 仅编码发送选择位置 **S** 的潜向量：传输内容为 (bXc_S, bZ, s)。
- **理论分析**：当选择区与非选择区信息密度相近（k≈1）时，码率约按选择比例ρ线性下降，即 B/B_tot ≲ η + ρ，其中η为边信息开销。
- 服务器端对未选择潜变量位置使用**预测均值填充**，提高相邻选择区域的重建质量。

**（2）层选择性注意力展开（Layer-Selective Attention Rollout）**：

- 计算方式：R = Ã_Le · Ã_{Le−1} ··· Ã_Ls，其中Ã_l = E_h[A_l,h] + I。
- 与已有方法的关键差异：
  - 最后层注意力遭受最终层"背景漂移"问题；
  - 全层注意力展开累积早期层噪声；
  - 梯度加权注意力需要反向传播，计算代价对资源受限客户端过高。
- 通过**排除噪声早期层、包含最终层**，在单次前向传播中实现更精确的任务相关性估计。
- 对DeiT-Tiny（12层），选定 (Ls, Le) = (7, 12)。

**（3）可学习代理Token替换（Surrogate Token Substitution）**：

- 为未选择位置分配单个可学习代理Token x_sur ∈ R^{1×D}：ex_{i+1} = s_i·bx_ti + (1−s_i)·x_sur + e_i。
- 仅优化这一个Token向量（D=1024参数），**骨干网络冻结**，保持完整输入行为不变。
- 使用分类目标训练，学习"指示信息缺失"而非提供错误视觉证据。
- 在不可靠信道上，对因丢包损坏的Token位置同样可用代理Token替换，增强鲁棒性。

### 6. 主要结论与发现

1. **率-精度权衡全面领先**：所提框架在1.24 bpp达到85.83%精度（仅比服务器上限低0.98个百分点），在可比码率下优于所有三类基线（语义通信方案、手工编解码器、任务无关LIC）。
2. **选择性潜变量传输优于像素域传输**：与同样利用任务相关性但在像素域传输的框架[33]、[34]相比，优势主要来自LIC的率效率。
3. **任务相关性比改进熵建模更有效**：基于简单均值-尺度超先验的选择性传输优于更先进的ELIC模型，说明任务相关性引导的潜变量选择比单纯优化重建导向熵建模更有价值。
4. **层选择性注意力展开更精确**：排除噪声早期层的注意力聚合在主流工作区域优于最后层注意力、全层展开和梯度加权注意力，且无需梯度计算。
5. **代理Token替换显著提升鲁棒性**：在包擦除信道下始终优于直接重建推理和选择补丁推理。
6. **均值填充提升重建质量**：通过条件期望（超先验预测均值）填充缺失潜变量能改善相邻选择区域的重建，从而提高下游精度。

### 7. 优点

- **模块化设计**：三个预训练组件无需端到端联合训练，可独立替换升级，部署灵活；
- **理论分析扎实**：提供了选择性潜变量传输码率减少的理论上界（公式10），从理论上阐明了约线性增益及非线性增益的边界条件；
- **单次前向传播**：层选择性注意力展开在不进行计算量大的梯度计算前提下，达到与梯度加权方法相当或更好的效果，对资源受限客户端极为友好；
