## 摘要
为无线资源管理设计机器学习算法是劳动密集型的：架构、损失函数和训练方案都需要手工指定。我们证明，这一设计层可以完全交由自主智能体处理。我们采用自主研究协议，其中一个人工智能编码智能体修改训练脚本，运行一个固定预算的实验，并根据一个不可变的指标决定保留或丢弃更改。我们授予智能体对架构族、输入表示、输出参数化、损失函数和任务采样法则的权限，并设定了一个因其难度而选定的目标：多小区网络中的和最小百分位速率功率控制。该公式针对小区边缘吞吐量，且是非凸、非光滑的，在其最大最小顶点之外是强NP难的。保障措施使结果可信：一个哈希固定的评估器、一个强制的推理契约和每个实验预先注册的伪造者。在二十六小时内的八十一次无人值守实验中，智能体在一次固定成本推理中达到了收敛的minorization-maximization参考的99.5%，推理成本降低约600倍，从第一个工作架构起缩小了94%的差距，并且一套参数适用于所有网络规模和百分位目标。它恢复了可证明的结构而非调整的常数：它发现的输出参数化在最小百分位处精确复现了最大最小最优分配，对于训练权重的每个值都如此。

## Abstract
Designing machine learning algorithms for wireless resource management is labour-intensive: the architecture, the loss function and the training recipe are all specified by hand. We demonstrate that this design layer can be surrendered to an autonomous agent in its entirety. We adopt the autoresearch protocol, in which an AI coding agent edits a training script, runs a fixed-budget experiment, and retains or discards the change according to a single immutable metric. We grant the agent authority over the architecture family, the input representation, the output parameterization, the loss function and the task-sampling law, and set it a target chosen for its difficulty: sum-least-percentile-rate power control across a multicell network. The formulation targets cell-edge throughput and is non-convex, non-smooth and strongly NP-hard away from its max-min vertex. Safeguards render the results trustworthy: a hash-pinned evaluator, an enforced inference contract and a pre-registered falsifier per experiment. In eighty-one unattended experiments over twenty-six hours, the agent reached $99.5\%$ of a converged minorization-maximization reference in one fixed-cost inference pass, at roughly $600\times$ lower inference cost, closing $94\%$ of the gap from its first working architecture, with one parameter set serving every network size and percentile target. It recovered provable structure rather than tuned constants: the output parameterization it discovered reproduces the exact max-min-optimal allocation at the minimum percentile, for every value of the trained weights.

## 2. 论文提出的方法论

### 2.1 自主研究协议（Autoresearch Protocol）
- **三文件架构**：
  - `prepare.py`：不可变评估器，实现 [15] 的信道模型（七个包裹六边形小区、COST231路径损耗、瑞利衰落），在固定的已固定随机种子的预留数据集上评分，SHA-256哈希每次迭代验证，代理无法篡改。
  - `train.py`：唯一可被代理修改的文件，包含模型、损失和训练循环，且文档字符串内积累追加式变更日志。
  - `program.md`：研究章程，规定目标、指标、参考标准、推理契约和探索协议。
- **外层循环流程**：代理阅读章程和日志 → 提出**单一假设**并附带**预注册的伪造者**（何种观察将证伪该假设）→ 编辑 `train.py` → 运行内层训练（2000步Adam，约1–2分钟CPU）→ 在17配对网格上评估 → 若 `HELDOUT SCORE` 改善超过噪声带±0.0005则提交（git commit），否则回滚。无论结果如何，包含伪造者是否被触发的信息都会追加到日志。
- **探索广度控制**：最多打开6个架构族；新架构族有保护期（固定数量的实验内不可被回滚）；若到期未超越现有最优则放弃；预算向最有希望的方向集中。

### 2.2 安全防护机制
- **哈希固定评估器**：防止自改进系统最常见的失败模式——让测试变容易而非让模型变好。
- **推理契约**：整个评估网格的推理时间限10秒，禁止测试时逐实例优化（伪装成摊销模型的迭代求解器将报异常而非得分）。
- **预注册伪造者**：将实验日志转化为可解释的发现序列，包括负面结果。
- **样本匹配**：消除不同随机实现之间的方差；在第63个实验时进行的中期审计纠正了一次样本匹配违规。

### 2.3 发现的冠军模型结构
- **经典脚手架**（无可训练参数的精确代数部分）：
  - SINR均衡递归（固定点迭代）：`p ← Pmax * w⊙F(p) / max(w⊙F(p))`，其中F为干扰加噪声除以信道增益。
  - **命题1**：此迭代的固定点恰好是均衡SINR为`cw`的点；当w为全1向量时为最大最小速率最优解`p*(H)`；从任意正初始值收敛。
  - **Kq-截断锚**（clip anchor）：通过`w_clip = min(γ_fp / thr_fp, 1)`驱动固定点迭代得到`p_clip`——均衡高于阈值的用户，但拒绝将网络拉低到全功率几何结构已遗弃的用户水平。Kq=1时退化为精确的max-min最优。
- **可学习组件**：
  - 24个逐用户输入特征，8个块：基础增益、固定分配下的SINR探针、最大最小工作点、全局顺序统计量、Kq截断均衡、集合受限干扰耦合、小区内上下文、(K,Kq)条件。所有特征都是(H,Kq)的闭式函数，**不评估速率或SLqP目标**，因此是问题的固定函数而非部分解。
  - 编码器：置换等变，结合细胞介导的消息传递与增益偏置双向注意力路径（约11.5万权重）。
  - 输出头：不直接发射功率，而是对锚定轮廓`w_clip`发出有界乘法修正，零初始化（初始权重使修正为1），训练从经典策略出发学习偏离。
  - **截断钳（cut clamp）**：将发射轮廓的超过阈值部分全部钳制到阈值，再通过固定点迭代(3)得到最终功率。**命题2**证明：当Kq=1时，对任意训练权重θ，模型输出精确等于max-min最优分配p*(H)，与参数无关——该列不可能退化。

### 2.4 训练目标
- 损失函数：`L = -f_Kq(r(p_θ(H))) / f_Kq(r(Pmax·1)) + α_T·L_distill`。
- 第一项是归一化的真实SLqP目标（按各任务自身的全功率SLqP归一化）——该归一化（第2个实验引入）是整场战役中**最大的单项增益**，因为原始目标的梯度幅度随Kq缩放，会饿死小Kq场景。
- 第二项以恒定权重α_T=1.0蒸馏缓存教师轮廓（短局部搜索从锚w_clip初始化），在规范固定对数轮廓坐标中单向比较。
- 任务采样：每步采样8个独立(K,Kq)任务，K均匀取自{1,...,10}（含评估网格中不存在的{3,5,7,9}），百分位连续横跨带域，排除Kq=1（命题2保证其最优）。优化器为Adam，峰值学习率2e-3，余弦退火。递归(3)被微分穿透。

## 6. 论文的主要结论与发现

1. **性能结论**：81次无人值守实验、26小时内，代理收敛到1.4775，达到QFT参考1.4850的**99.5%**，推理成本约600×更低，且为单次固定成本前向推理，无逐实例优化。从第一个工作架构（92.2%）闭合了94%的性能差距。
2. **泛化结论**：一套参数服务所有网络规模K∈{1,...,10}和所有带内百分位目标（0, 0.25]，且不受包裹效应限制。
3. **可证明的结构发现（而非调参）**：输出参数化发现的截断钳+固定点迭代结构使得Kq=1时模型对所有训练权重值θ都精确输出max-min最优分配（命题2）。代理自己识别并利用了这一性质。
4. **研究角色再定义**：人类贡献缩减为陈述问题与构建公正评估器；算法设计层可被完全自动化并保持可信、可审计。
5. **模板性结论**：结合文献[7]（信道估计任务中代理搜索收敛到已知最优的LMMSE），论文提出更尖锐的论断：**代理搜索恰好在经典解已是最优的地方恢复经典解，在经典解不足的地方产生新结构**。收敛到经典形式是问题的诊断而非方法的局限。
6. **负面发现**：蒸馏自参照求解器本身不如自训练学生；目标软化、能力增加、百分位重加权等方向均失败。
7. **饱和诊断**：最后约12个实验中对新机制的尝试全部回滚，仅参数级改进继续支付报酬——搜索已饱和于当前最强已知性能水平。
